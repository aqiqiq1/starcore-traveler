# 素材 Agent 任务书：轻甲探险者与悬空古遗迹

## 1. 任务目标

为单人像素风横版解谜冒险寻找与现有主角美术风格接近的地图素材，其次寻找表示星核的物品或特效。允许下载免费且许可明确的候选包以检查文件；审核后删除本轮不合格包、解压文件及预览，仅留简短淘汰理由。不批量囤积，不删除或改动用户已有主角与文档。

最终目标是一套可用于首个原型的地图主素材及匹配的星核表现。最多保留两套合格地图组合供用户选择，背景可随主包附带，不为每种机关准备多个备选。人物的细节密度、配色、轮廓和比例匹配优先于素材名称是否包含“遗迹”。

## 2. 项目与世界设定

- Godot 4、Windows、约一个月、四人小组、AI 辅助、三个短关卡 Demo。
- 古老文明曾用“两极之力”建造悬浮城邦；文明消失后，城邦崩裂成云海中的遗迹。
- 主角是身穿轻甲、系紫红围巾的年轻探险者，佩戴可切换两极之力的护符。他在遗迹中寻找星核，归路断裂后，需要借残存机关唤醒出口大门。
- 三关为断桥庭院、沉寂回廊、云顶圣所，共用一套主地形，不各找一套画风。
- 不做战斗、敌人、背包、技能树、复杂剧情或多套世界主题。

玩法用于理解物件需求：角色跑跳并切换极性，同号相斥、异号相吸；借固定符文石跨越障碍，推拉一个星核进入石座开门。星核主要在连续地面运输，角色可从侧路绕行。不需要火器、科幻终端或机械空间站。

## 3. 主角参考：必须先看，再选环境

参考同目录 `individual_sheets/male_hero-*.png`：

- 轻甲、人形、敏捷冒险者，紫红围巾是明显视觉特征。
- 透明 PNG，每帧 128×128；画布包含大量留白，不能把人物当成 128 像素高。
- 跑步实际可见高度约 33～36 像素；跳跃/下落受姿态和围巾影响，尺寸会变化。
- 已有 idle、walk、run、jump、fall、fall_loop，不另找主角，不为攻击动画新增玩法。
- 人物文件结构已检查，但未验证 Godot 内播放，来源与许可待创作者补充。不要因“用户提供”而判定已经获得发布授权。

若组员的工作目录没有人物图，请先索取至少一张原尺寸动画表，不仅凭文字匹配精细度；不重新开始搜索主角。

## 4. 美术 brief 与筛选优先级

### 必须满足

- 像素艺术，横版侧视，可拼接地形；不把俯视图或纯背景插画当成平台 tileset。
- 古代石质遗迹：风化石砖、平台、墙面、端头和转角，包含适量裂痕或残缺结构。
- 与现有人物的细节密度、轮廓和尺度协调，不使用过于简陋、放大后像素密度明显不一致的组合。
- 地形落脚边界清楚，可用于配置 Godot 碰撞。
- 来源、许可及实际适用条款可以追溯。

### 优先但不苛求整包现成

- 残缺拱门、断柱、苔藓藤蔓、少量碎石，表现古老与失修。
- 开阔天空、云海、远处建筑/浮岛剪影；古老但不必阴暗，不以血腥恐怖地下城为主。
- 背景低于前景对比，紫红围巾与角色身体在场景中可见。
- 浮空、断桥可通过布局和平台端头表现；符文微光可后续自制，不要求一个包包含完整悬浮神殿。
- 尽量同作者或同系列组合，但不是硬要求。

### 本轮资源顺序

1. 主地形一套：平台、墙、转角/端头及少量遗迹装饰。
2. 表示星核的物品或特效一套：清晰的小型晶体、球形核心或发光遗物，可静态或轻量循环动画；与人物和地图统一，便于显示正负标识，不能只有难辨认的粒子，不引入新机制。
3. 背景作为地图补充，优先随主包取得，不扩大检索；门、石座、符文石和静态尖刺记录主包可复用情况即可。

字体、音效、音乐可以下一阶段再补，本轮不为“全覆盖”扩大检索。UI 按钮、范围圈、箭头与正负标识可用 Godot 控件/代码绘制。极性转换机关不在必做主线，不寻找专属素材。

## 5. 技术适配检查

- 优先透明 PNG、精灵表、常规 tileset；不依赖其他引擎的专用运行功能。
- 逻辑画面暂从 640×360 考虑，16×16 或 32×32 地形均可，但需说明与人物实际尺寸的比例；不要把网格尺寸当成唯一筛选门槛。
- 区分贴图尺寸、图块尺寸和可见对象尺寸，说明边距/间距、端头/转角和自动拼接是否齐全。
- 记录哪些是可用构件，哪些仅为作者演示合成图；后者不冒充可直接游玩的关卡。
- 可接受轻量拆帧、拼接或少量机关自制；需要大规模重绘或整体换色的候选不作首推。
- 只有页面证据就写页面已核实；实际下载查看后才写文件已检查；未启动 Godot，不声称导入、碰撞、比例已通过。

请交付一份 `素材候选报告.md`，包括：

1. 主推荐地图一套，必要时备选一套；明确名称、作者、原始链接与下载位置，再单列匹配的星核物品/特效。

4. 已核实的网格/格式与许可证据；未知项明确保留，不编造。
