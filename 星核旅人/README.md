# 星核旅人 · 项目导航

先看本页找文件；当前状态见 [progress.md](progress.md)，后续工作见 [TODO.md](TODO.md)。

## 先运行哪个

用 **Godot 4.7.2** 打开 `基础场景原型/project.godot`，按 **F5** 从第一关内置标题菜单进入，通关后从完成页继续到第二、第三关。单关调试可打开 `scenes/level_02.tscn` 或 `scenes/level_03.tscn` 按 **F6**，不代替完整路线验收。旧沙盒 `scenes/main.tscn` 不是启动入口。

- **第二关**：分路运输、联动仓唤醒、借力越台、最终入仓再到出口。失败回最近稳定仓，R 整关重来。两台都用真实受力驱动晶面金／青偏色，撤力回紫。
- **门与入城**：L1/L2 出口从门槛向上展开；L3 入门渐暗，角色先保轮廓，再由实际右柱遮挡。见[紫晶与门效验证](基础场景原型/docs/L2_GATE_VISUAL_POLISH.md)。

**三关 Demo 从断桥后的前行讲到主角入城，后续故事留给正式版。** 尚无已验收的 Windows 独立发行包。

## 顶层目录用途

- **`基础场景原型/`：唯一Godot工程。** 游戏内文件统一从这里找，不在素材源目录直接改运行版本。
  - `scenes/`、`scripts/`：场景和代码；是否属于产品以入口、导航和真实依赖为准，不以目录名判定。
  - `assets/`：实际运行所需资源副本；不要当成“与素材库重复”而删掉。
  - `docs/`：玩法机制、编辑方法和验收边界。
  - `tests/`：测试/捕获入口；`tests/logs/`是既有测试证据，不需要日常打开或全量重跑。
  - `tools/`：素材生成、截图等辅助工具，不是游戏入口。
  - `screenshots/`：保留的引擎截图及说明；历史已归档图片见目录内清理说明。
  - `.godot/`：Godot生成的导入和编辑器缓存，不手工整理内部结构。
- **`individual_sheets/`：主角原始素材。** 保留，来源/许可尚待确认。
- **`素材库/`：组员提供和收集的第三方素材源。** 保留两套 Golem 原包；不能据文件名推定许可。
- **`自制素材/`：概念、批准原稿、生成脚本和历史美术方案。** 当前主要批准版本包括第二关V3平台、DS03背景、石碑/石柱/符石/门等。V1/V2/DS01/DS02不是自动可删项：可能有对比、生成或追溯用途。
- **`项目归档/`：低频历史资料与整理记录。** 不参与Godot运行；截图归档可按记录恢复到原路径。
- **`.openchamber/`：会话/工具元数据。** 本轮不搬动或清理。
