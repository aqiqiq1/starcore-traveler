# 历史截图说明（原640×360截图记录）

> 2026-11-12归档：本文件是历史记录，不是当前截图清单。部分原图已从工程screenshots目录移入 `项目归档/历史实验截图_20261112.zip`，具体以同目录清理JSON为准；原图未被改造成新截图。

> **重要：本目录混有三批实际截图，不代表同一版操作。**
> - `01`–`20` 是**加入 walk/默认步行之前**的旧版截图：HUD 没有 `L-SHIFT: RUN` 提示，`run` 是 `show_showcase` 定帧的旧默认/特写。它们仍是**真实引擎捕获**，对 idle/run/jump/fall 的护符几何仍有效，但**不能用来判断当前默认移动或当前 HUD**。
> - `21`–`22` 是加入 walk/sprint 后的**新版 walk 实机定帧截图**，使用当前 HUD。当前默认移动请以 21/22、README 和自动测试为准。
> - `anchor_01`–`anchor_04` 是本轮**单锚点借力房**截图：01/02 是定帧，03/04 是脚本物理运行静帧。它们不是录像，也不代表手工连续试玩。
> - `CONTACT_SHEET.png` 顶部也标注了 01–20 legacy / 21–22 post-change。原始 640×360 PNG 是主要证据。

本目录截图由 `tools/capture_screenshots.gd`（基础房）和 `tools/capture_anchor.gd`（借力房）在运行中的 Godot 4.7.2 真实主场景中调用 `get_viewport().get_texture().get_image()`（等待 `RenderingServer.frame_post_draw`）保存。不是预渲染图、不是源素材拼贴冒充截图。

- 工程窗口：1280×720；逻辑视口：640×360；`display/window/stretch/mode="viewport"`；Nearest；因此这些 PNG 是 640×360 的实际逻辑视口输出，窗口会 2× 最近邻放大。
- 每张图顶部有**引擎内捕获标签**（由捕获场景 CanvasLayer 绘制）：
  `ENGINE CAPTURE 640x360 | 动作 #0-based帧 | 朝向 | 极性 | 胸口锚点 | 可选 RING/DEBUG`。
- 右下角是游戏 HUD 的实际状态面板；它使用 1-based 的 `FRAME n/total`，与捕获标签的 0-based 帧号不同，两者都是真实状态。
- 捕获使用 `PrototypePlayer.show_showcase()` 冻结特写姿势（关闭物理、指定帧/朝向/极性/位置），因此不是“实时输入录像”。实时物理、walk/run 输入、双击/Shift/echo、碰撞、重置、暂停、Q、F2 和借力房由 `tests/test_runner.gd` 的 headless 断言覆盖（当前 **301 PASS / 0 FAIL**）。
- 所有图都没有经过调色、合成或重绘；`CONTACT_SHEET.png` 和 `WALK_ADDENDUM.png` 只是实际截图的最近邻拼图。原始 PNG 是主要证据。
