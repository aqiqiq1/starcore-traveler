# 基础场景与单锚点借力房功能审查

## 结论

当前工程通过本轮功能验收：原基础场景的移动、护符和调试保持可用；按 F2 可进入独立可玩的单锚点借力房，Q 在该房间真实切换吸引/排斥，固定正极、有限范围、实体遮挡、近距平滑、速度上限、暂停冻结和 R/落坑恢复均已接入。原 200 条断言全部保留并通过，本轮共 **301 通过、0 失败**。

借力房是单锚点试验，不是完整三关：F2房内没有星核运输、石座、门或核心。符文石现复用32×32包壳星核视觉，固定正极、近距显示悬浮提示，无实体碰撞；F7另用于真实星核仓记录/符石联动测试。当前美术为原型版待用户实机确认。

## 当前操作

- A/D 或左右方向键：行走，100 像素/秒。
- 左Shift＋方向：奔跑，160 像素/秒；左Shift可在行走途中按下，松Shift回行走；右Shift无效。
- 同方向0.25秒内双击，第二击按住：奔跑；松方向或换向取消。键盘重复事件及同时按等价方向键不算双击。
- 空格跳跃；Q 切换极性；R 重置当前房间；Esc 暂停；F3 调试；F2 在基础房与借力房之间切换。
- 基础房中的 Q 只改变护符/HUD；借力房中的 Q 驱动真实力场。
- 借力房路线：F2 → Q（CYAN，吸引）→ 跑跳向断桥、保持向右 → 越过符文石后 Q（GOLD，排斥）→ 落上右侧宽台。HUD 显示 ATTRACT / REPEL / OUT OF RANGE / BLOCKED / COMPLETE。
- 失败：落坑自动重生；R 随时恢复出生点、GOLD、idle、速度零、成功状态清除；无生命次数。

## 边界与下一步

- 借力房没有永久遮挡物；BLOCKED 规则用测试临时实体块验证。正式关卡需要设计自然遮挡点位，不能让玩家只在测试里见到该状态。
- F2与F7共用同一套32px概念直接转换的sleep/gold/cyan三态图（96→32 NEAREST），F2保持原力和坐标；新外观未视为最终美术定稿。起点和落点仍用现有Szadi图块。
- 没有星核、运输、石座、门、三关、存档、结算、音频和 Windows exe；本机缺少匹配 4.7.2 导出模板。
- 角色来源许可待补，外部分发前必须确认。
- 建议下一步由创作者实玩当前借力房，评价符文石可读性、切换窗口手感和落点宽度；确认后再做单核心运输，不自动扩展为三关或正式美术。
