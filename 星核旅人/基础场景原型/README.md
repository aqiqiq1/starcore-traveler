# 星核旅人 · Godot工程

更新：2026-11-13。项目导航见 [上级README](../README.md)，当前实现见 [progress.md](../progress.md)，后续工作见 [TODO.md](../TODO.md)。

## 1. 启动

使用 **Godot 4.7.2** 打开本目录的 `project.godot`。

- 正式试玩：打开 `scenes/level_01.tscn`，按 **F6**。标题开始 → 第一关完成页 → 进入第二关 → 运输星核 → 入仓后走到出口。
- 独立第二关：打开 `scenes/level_02.tscn`，按 **F6**。
- 敌人训练场：打开 `scenes/experiments/polarity_golem_experiment.tscn`，按 **F6**。
- **F5仍运行旧 `scenes/main.tscn` 沙盒**，不是正式两关。旧沙盒保留F2借力房、F4仓互动、F7记录实验。

逻辑画面640×360，Nearest采样；正式菜单有音量、窗口/全屏和显示确认回退。设置不代表已有音乐/音效内容。编辑器预览与运行时效果并非所有旧场景都一致。

## 2. 操作

- A/D或左右方向键：行走；左Shift＋方向或0.25秒内同方向双击并持续按住：奔跑；右Shift不触发。
- 空格：跳跃；Q：切玩家自身的辉相／澜相；R：重置当前场景/关卡。
- 正式关Esc：暂停菜单；第一关F：与附近守望者残响交谈；第二关F：主动阅读入口石碑，E：近仓释放/主动入仓。第二关失败回最近稳定入仓点，R仍整关重来。
- 独立敌人实验：**J单次挥击、Tab切怪物相性、Esc简单暂停**。新版正式两关均无战斗；守卫保留给后续第三关门前，第三关尚未制作。

同相相斥、异相相吸；地形阻断实际中心连线。星核主要通过极性运输，不能手持、投掷或靠身体顶推；**没有自动入仓，需满足范围后按E**。

## 3. 当前可玩内容与边界

- 第一关：借符石登台和跨坑、恢复点、到出口完成；菜单进入和原开场流程保持。两处石碑作为“守望者残响”的载体：远处只有碑，走近显现，再靠近提示F主动交谈；离开淡去，不锁移动或要求读完。碑本身不自动讲解。
- 引导者最终形象已于2026-11-13原样接入上述两处：6×48×64、4fps，保持批准预览的像素/比例/配色/深色细边/虚影及空手臂。第二关仍保留石碑，没有新增NPC。后续地面接入不改上述人物、第一关HUD/对白与几何。
- 同日后续新增靠近显现：96px内淡入0.25s，112px外淡出0.20s；交谈仍56/66px，F主动开页。投影相对石碑上抬18px，台词与人物PNG不变；新增碑仅为视觉载体，无碰撞，不影响借力。见`docs/GUIDE_ECHO_CARRIER_20261113.md`。
- 新版第二关：1792px（约2.8屏），起始仓→安全运到中继仓→人上桥/核过20px低廊→联动仓记录→符石亮起→取核保留记录→借力越80px石栅高台、右侧接核→最终仓→出口。共四仓、单活动核、无守卫。入口石碑4短页，F主动阅读，不自动弹页。
- 独立敌人实验：怪物有界巡逻、警戒接近并短预警砸击，命中使玩家短退，不扣玩家HP。同相攻击扣怪物血并击退/打断，异相牵引不扣血、不取消砸击；头顶血条，3点血击散后等待8秒倒放重组。这些是试验参数，非正式平衡。
- 不是完整三关Demo；未做第三关、正式战斗关、背包/技能树/联网或跨启动关卡存档。
- 新二关中继/联动稳定入仓后可分段恢复；死亡/核越界一起恢复玩家、核所在仓及关联状态，同仓重存相性更新恢复记录。R整关清空；只有最终仓锁定、关联记录/符石已实际生效且玩家到出口才结算。完成页重玩/返回标题，不跳尚未制作的第三关。
