## 启动与试玩

用 **Godot 4.7.2** 打开 `project.godot`。F5 运行 `res://scenes/level_01.tscn`，从内置标题菜单开始，完成页继续到第二、第三关。F6 可独立调试 `scenes/level_02.tscn` 或 `scenes/level_03.tscn`；旧沙盒不是启动入口。逻辑视口 640×360，Nearest 采样。完整键位以游戏内暂停页为准。

1. **L1 断桥**：借符石登台、跨坑并到出口，两处残响靠近显现后主动交谈，不锁移动。
2. **L2 回廊**：用极性运核，联动仓首次完整入仓唤醒两座紫晶平台，再运至最终仓并走到出口。入仓需要主动操作；失败回最近稳定仓，R 整关重来。受力穿晶时，两台各自金／青偏色，撤力回紫。
3. **L3 入城**：运输、启用浮地、面对守卫，取得门核并真正走入城门。实际入口遮挡由右柱构件承担。

首次遇到核心机制会暂停弹出演示：左侧为真实关卡循环，右侧说明；`F` 翻页/关闭，长按空格跳过整窗。

设置里的窗口档：640×360、1280×720、1920×1080（无边框，3× 整数缩放）；全屏走桌面分辨率。1920 档会盖住任务栏，要留任务栏就用 1280。

## Windows 交接与许可

从当前工作区选择匹配 4.7.2 的 Windows Release 模板，导出到空目录，解压或复制到独立位置再双击；若分离 `.pck`，与同名 `.exe` 同目录。先确认标题、中文、声音和设置，再走完关卡切换与入城。`--import` 与无界面载入通过不等于 Windows 成品运行通过。此轮不替创作者导出或启用加密。
