# 长按跳过反馈参考记录（2026-11-19）

本记录只用于本轮 `skip_progress` 小条 UI。参考核看时间为 2026-11-19。

## 已实际打开并观察的证据

1. **GTA San Andreas + Mission Hold Skipper（实际游戏画面，非宣传图）**
   - 页面：https://github.com/ricardoofnl/mission-hold-skipper
   - 原始截图（已下载）：`tests/skip_progress_20261119/references/gta_sa_mission_hold_skipper.png`
   - 画面身份：Drive-By 任务过场，1920×1080，按住 ENTER 时。
   - 实际观察：
     - 提示固定在画面**右下角**，离底边和右边都有小间距。
     - 文字标签 `HOLD ENTER TO SKIP` 在**指示器左侧**，右端对齐并紧邻指示器；标签本身不压住底部居中的字幕。
     - 指示器本体很小，只占画面宽度的约 2%；未填充部分在暗背景上仍可辨认。
     - 只在按住时出现，填充随按住时间推进。
   - 可借鉴：右下角位置、标签放左侧、与字幕保持距离、只在蓄力时出现、体量小。
   - 不能照搬：它是圆形扫描环、白色系、GTA 的字体与比例；本项目要的是 96×6 横条、工程暂停面板配色。

2. **Hi-Fi Rush 长按跳过说明（二次文字资料）**
   - 页面：https://twinfinite.net/guides/how-to-skip-cutscenes-in-hi-fi-rush/
   - 访问：正文可读；页面图片未逐一核看，且该页直接抓取返回 403，只核对了搜索返回的正文。
   - 实际观察（文字，不是画面）：按住 Q/B 一段短时间后，**画面右下角**出现 meter，随按住时间填充；松开不触发跳过。
   - 可借鉴：右下角填充条这一形式、按住才出现、松开取消。
   - 未核实：没有拿到 Hi-Fi Rush 的第一手截图/视频帧，因此**不引用它的配色、尺寸、具体条形状**。

3. **Shadow Man Remastered 更新说明（二次文字资料）**
   - 页面：https://steamcommunity.com/app/1413870/allnews/
   - 实际观察（文字）：补丁说明明确写有 “Hold To Skip bar and text”，并规定显示有最短时间。
   - 可借鉴：条 + 文字成对出现；短按不应造成闪烁提示。
   - 未核实：没有核看游戏内画面，只作为“短按不显示”的旁证。

## 不能从参考得到的部分

- 96×6 的像素尺寸、`(528, 336)` 坐标、“跳过”两个字、近黑底/青灰 1px 边/金色填充，来自**本轮用户规格**与工程已批准的暂停面板样式（`scripts/ui/pause_menu.gd`），不是从上述游戏照抄。
- 未从参考中照抄任何第三方像素、字体或 UI 素材；本轮不新增图片素材。

## 结论

参考支持：右下角、小体量、左侧标签、仅长按蓄力时出现、松开取消、不要压住字幕。
本轮按用户给定的 96×6 横条和工程既定配色实现；Hi-Fi Rush 的具体第一手画面未取得，已在报告中列为局限。
