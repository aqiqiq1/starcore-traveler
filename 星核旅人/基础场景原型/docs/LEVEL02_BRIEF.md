## 目标体验与最小闭环

左侧E释放唯一星核 → Q切至与核同相，从左侧排斥推送 → 星核走下层低廊，玩家借台阶/跳跃走上层 → 右侧下行接应、切异相拉核 → 核在目标座位且玩家邻近时E入仓 → 目标仓锁定后玩家到出口完成；R可重玩。

## 机制保持不变

- 玩家100/160速度与原跳跃不变；核碰撞12×16、玩家12×30，身体不能顶推核。
- 核运输参数保持100范围、40内零力、64满力、18外缘渐弱；620/300双向加速度；核限速120、地面阻尼420。保留地形阻断中心连线和接地水平投影，不能为过图改手感或穿墙力。
- 释放接受时快照为玩家相反相性，开罩中Q不改核；沿用40px远侧出料/0初速/0.25s罩动画。
- 入仓必须E，玩家—仓46px、玩家—核80px、核在仓座±24×18px；无自动捕获、速度门槛或相性配对。入仓记录核自身极性，取走后保留记录，R清记录。
- 目标仓当前锁定才可完成出口，开罩取走后不再允许完成。入仓本身不是过关，尚未入座先到出口只能得到未完成提示。
- R回出生点、辉相、起始仓锁核/目标仓空开、清完成及在途动画；暂停冻结物理/罩/背景，失焦清输入，不自动带核或卡死。

## 尺寸与可解性约束

- 楼板/台阶是正常实体，不为核单独关闭碰撞或射线。低廊净高初值可取20px（高于核16、低于玩家30），实测安全余量后再定。
- 低廊长度及推行位置必须适配100px范围。建议先用约64px短廊；不要让核卡在长廊中间，再偷偷取消阻尼/遮挡或增大力场。
- 参考可行起点：地面y320，低廊底y300，玩家力场中心y305、地面核中心y312；中心连线可从低廊下通过，而身体不能通行。此为待物理验证的布局假设，不是已证实结果。
- 上层入口台阶不得把推行位置提前挡在核力场之外；可用下方仍可走人的高位短台阶，玩家回退跳上首阶。用现有跳跃能力验证上台和右侧接应，不依赖帧级竞速。
- 原仓释放点含单屏16～624硬边界，因此优先把仓及通路留在640宽度内；不改共享仓脚本来扩图。
