# 第二关守卫接入后：下一轮美术优化建议

> 更新：用户后续已授权直接实施全关美术优化。暖灰地面、五缝刻槽、左高台收口/遮挡、字号与提示减负均已落实，结果以 `ART_GUIDE_PASS_20261112.md` 为准。本页保留为前轮审查依据，不再把已完成项当待批准任务；守卫原双色保留，未作无必要的整图染亮。

日期：2026-11-12。依据当前引擎实机图 `screenshots/level02_guard_01_bridge.png` 与 `level02_guard_02_stele_rules.png`。本页是**建议，不是已批准重画任务**；本轮没有替换地图、改色源图或新增美术包。可读性判断属于协调者观察，尚非玩家测试结论。

## 优先一：让已有玩法更容易看懂

- **上层施力缝**：当前连续顶缘把真实8px力场通道藏起来，只剩细小嵌缝，玩家容易误以为整段桥面都能施力。建议在五个原缝位置做同风格的短刻槽/浅色边缘提示，让它们在640×360下可辨；不扩洞、不取消遮挡、不改变已批准的桥面大轮廓。先出局部示意确认，再动decor层。
- **仅凭颜色辨敌相**：现在头顶已无极性提示，橙金/青蓝大多集中在守卫关节和突出石片。先保留这两套源图；若试玩仍难分，优先小范围增强核心/关节色块与亮度层次，不把整只怪物统一染成荧光色，也不改主角围巾。守卫攻击预警与受击闪色需短暂，不能长时间盖住其固定相性颜色。

## 优先二：减少材质和边界不一致

- **地面与桥身统一石材**：桥台偏浅暖灰，地面边缘仍偏暗褐、颗粒密度较高。建议以已批准的桥身/石柱暖灰系为基准，局部统一地面顶缘与过渡砖，而不是重新搜一整套tileset或整体给场景加滤镜。远景继续低对比，不跟前景争清晰度。
- **左高台台下饰面**：本轮右短台碰撞已对齐视觉底y300；左高台仍存在饰面比真实薄碰撞向下延伸的既有差异。建议单独预览收短/调整左高台下沿的方案，避免人物从下方经过时与石体重叠。此项涉及批准切片，须确认；不要直接加厚左高台碰撞，那里是现运输解法需要的玩家通路。

## 优先三：文字和界面减负

- 桥上两段世界说明仍为旧9px字，即使移开了血条，也不适合当主要教学。建议下一轮改为少量原生12px短标签，或把解释留在已更新的12px石碑中；避免同时显示完整教学句、常驻状态大面板和多条toast。
- 守卫头顶当前只留血条和中性重组倒计时，这一方向保留；不要重新加极性字/正负号。玩家现有HUD相性显示不属于被移除的敌人提示。
- 石碑六页内容覆盖新玩法，但不等于玩家一定会读完。试玩若显示阅读负担高，优先精简和重排，不继续增加页数或铺满桥面的文字。

## 暂时不建议做

- 不换主角、守卫或整套古遗迹地图，不放大角色来制造压迫感。
- 不做新的冲撞动画或大范围砸地光波；当前举臂落拳足以支持玩法，重点是动作/命中时刻同步。
- 不为“更好看”填平真缝、盖住核通道或改冻结运输物理。

推荐次序：先试玩桥上战斗与运输 → 确认施力缝/颜色是否难认 → 出一版局部标记与材质对齐示意 → 批准后再接入。无新增素材下载/购买要求；角色、守卫作者与许可仍须组员补齐。
