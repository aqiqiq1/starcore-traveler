## 2. 浮地：由全局计时改为逐块踩塌

- 删除20秒启动后全体回落。启动后平台真实升起；**没踩到的块保持稳定**，不因等待统一掉落。

- 可用约1.0–1.2秒踩踏到掉落、末约0.3–0.4秒抖动作首版候选，具体用真实跨块输入调至有压力但可通过，不以测试传送证明路线可走。

## 3. 守卫教学门槛与碎裂等待

- **第一次教学前**：守卫只用正常下砸/普通巡逻，绝不启用引力场、真伤弱点或真实场力。
- 无效击碎仍只损石壳不损3真伤进度；第一次石壳碎裂后进入`等待教学的碎石态`，可见最后碎石帧，**不自动重组**，不攻击不施力。
- 玩家未曾第一次无效击碎守卫之前，靠近/反复碰锁门**不强制触发电影**。不因脚本方便假设已经碎裂，不靠debug标志冒充真实击碎。
- 首次无效击碎成立且玩家随后接近门，才触发一次教学。过场开始即驱动这个真实碎石态重组，重组一结束立即展示引力蓄力，不夹两次普通攻击或额外长等待。
- **引力招自身**从蓄力动作第0帧就启用内收场/真实力，不再先等一段才开始。过场期间只展示该动作/场，伤害与玩家输入仍冻结，阅读/跳过不受罚；交还后马上从一轮新的引力招起手，有完整缩短后的反应时间。
- 电影记忆/门槛/碎石等待状态在普通恢复与R中的语义明确：普通战斗失败不重播已看教学；R清除首次碎裂与教学标记。教学前若已碎裂再坠落，不丢失真实碎裂事实或无条件提前开场。
- 教学后普通阶段再次击碎不能永久停尸等第二次教学；保留快速重组继续战斗，不清已有真伤。仅首次教学前有等待。

## 4. 新战斗节奏与异相判伤

- 过场交还后首招为**引力蓄力攻击**，之后循环：**正常下砸→正常下砸→引力蓄力攻击**。只有实际完成的普通下砸计入两次，不把起手/受伤打断当成一次。真伤打断引力招后进入该轮正常招节奏。
- 同一套J相性统一改为**异相有效**（普通破壳与易伤真伤均相反于守卫），避免教学前后两套攻击相性；同相J不记伤。保留起手相性快照、真实近身/前向剑命中、地形遮挡、每挥最多一次结算。
- 真伤仍只在**引力招易伤窗口**异相J命中，正常下砸期间打碎仍无效。前两次真伤换相、第三次真失活掉核开门保留，不降成一次击败。
- 删旧“吸近→Q切同相→顶斥力J”教学/常驻任务。新破法为读守卫相性、异相靠近/用吸引接近、在亮弱点窗口J命中，不强迫先切同相。
- 缩小当前过大的攻击/受击判定与引力范围/强度：旧J_REACH58/竖差40、场190→150/1650不再照用。可先试J有效距离约32–38、竖差约26–30、场约110–125、加速度约650–850；最终按真实输入验证，报告实际值。不能改共享玩家12×30身体来掩饰局部判定问题。
- 引力蓄力比原2.5秒短，可先约1.6–1.8秒；普通下砸预警独立，不能每次普通下砸都跑引力动作。
- **引力蓄满攻击**改身体周围360°判伤，不只身前。单次释放最多扣玩家一次；有与实际范围一致的可读近身环/地面预警（引力吸引半径不等于伤害半径）。普通下砸仍前向拳区，可合理缩小。测前后两侧同距离及外缘不命中，不能只换特效。
- 守卫活动平台明显加宽（例如原260扩到约500–600或合适值），同步巡逻/追击、安全退路、门/城内/镜头/触发与边界，不能只贴宽地面而AI仍挤原小区。不要凭宽度加入大量空走。
