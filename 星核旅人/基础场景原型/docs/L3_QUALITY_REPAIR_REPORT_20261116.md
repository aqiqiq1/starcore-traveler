**真实输入步骤（测试 `_sec_route` 全绿，截图 b02 同流程）**
1. 符石已点亮（setup 到存档点），从地面往右走进吸力：被抬起，落到右台 `(≈529,210)`。
2. 走到右台左缘（≈526），按住左 + 跳跃；在弧顶 `y ≤ 158` 按 Q 切同相，被斥力推出。
3. 落到高台 `(≈287,130)` ✓；向左走到装置 `(290,130)` 按 E（装置激活、浮地开始）。
4. 返回：走回高台右缘（390）→ Q 回到异相 → 起跳向右，被吸回右台边缘 → 短跳一步站上实体右台 →
   Q 切同相（被推向右）→ 沿右台向右走到浮地。

**这一版为什么能成**：此前只测了“地面平走/直线被吸”，轨道顶点在符石右侧约 +16px；
补测“从右台边缘起跳 + 空中 Q”后，Q 发生在符石左上方（`x < 符石x` 且 `y < 符石y`），
斥力方向是**左上**，正好把上升动量推上左侧高台。参数扫描（跳点 415/425/435、Q 触发 130..185、
从右台跳 vs 地面跳）的实际覆盖与失败都记在 `tests/level03/probe_a1.gd` 的最后脚本里；
成功组合即上面第 2 步，已连续重跑 3 次稳定。
