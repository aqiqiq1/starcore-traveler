## 4. 需要复核的决定 / 限制

1. **符石升流是 L3 取力闸的实现选择**：共享符石是原点引力，任何邻近平台都会被它变成
   传送带/绕圈陷阱（本轮实测：玩家在平台下方反复绕圈，`y` 只在 216–255 摆动）。因此 L3 用
   自己的 provider 把符石力改写成有边界的升流 + 平台净空，符石仍是唯一来源与相性判据。
   若你希望保持共享原点引力原样，就需要换成别的可达方案（例如另加一个 L3 升降装置）。
2. 平台是**单向碰撞**：升上去穿过、落下来接住；平跳（70px > 64px）上不去。
3. 教学等待碎石与两击重试的语义：重试时若正处于等待碎石，会保留该碎石态而不是静默“已教学”。
4. 气泡没有尖角尾巴（246×54 小底 + 1px 描边），标题行仍是“守望者残响”；未做打字机速度的设置项。
5. 旧首版截图/报告/日志未删未改；本轮不提交、不推送。

  最小改法是给平台一侧加一堵 6–8px 厚、从台面向上 40px 的实体挡墙（同样靠真实遮挡，不加隐形区），
