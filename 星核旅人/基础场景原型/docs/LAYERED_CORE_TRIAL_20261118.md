## 受力局部渐变

- 初稿仅玩家—活动星核的真实有效成对力，不含符石场，不增加真实范围/力强/穿透条件。
- Level02完成原物理计算后只读本帧有效状态/非零力、玩家中心和核位置、玩家相性。核心无效/仓内、超距、死区、被普通墙挡、锁定、重置/离场/完成时无目标显色，不能用旧有效值残留模拟真实作用。
- “穿过”在本初稿中以有效玩家—核作用线段与裸露星核质遮罩相交为视觉表征，不宣称计算了连续空间力场。线段未交材质就不显色；相交处周边形成柔边，不整片变色。
- 用片元到有限线段的距离乘星核质遮罩得到软权重。强度中心→边缘平滑衰减，初稿半径约10–16世界px、边缘羽化约6px，可据正常视口调整。石壳权重必须为0。
- 护符金/青决定局部色，不以吸/斥代颜色。Q改变目标色时渐变；出现/消失都以delta驱动平滑（试装约0.12秒起、0.25秒退），不强硬跳色。移动线段应连续跟随，不堆积永久彩色轨迹。
- 在可暂停CPU时钟推进，禁用不受暂停控制的Shader.TIME。冻结显示，暂停恢复无跳变；R直接清临态、黑底。允许shader仅用传入数据渲染。
