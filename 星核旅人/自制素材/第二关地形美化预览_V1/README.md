## 建议的审阅点

1. 新暖灰石与冷青背景的明度/色相分离是否足够，还是需要再压暗半档。
2. 6px 石梁在 640 原生尺寸下是否够“石作感”；目前用 1px 轮廓、错位接缝和崩边，未加厚。
3. 苔藓/水渍是否过量；当前约 9 处小簇，集中在接缝与墩脚。
4. 既有出口/柱子的暖褐色与新石材是否统一，还是新石材应再偏紫灰。
5. 目标仓在无标签预览里的辨识度是否可接受（实机有原标签）。

## 后续可选（未画、需改几何/另行批准）

若要让空中石件更像完整古建筑，可考虑在踏板/右踏板下加 1–2px 的低对比石托架，或把梁做成连续檐部；这会引入新的背层造型、可能影响“透空/可站”的读法，本轮没有暗画，也没有实装。建议先由用户确认当前这版的石材方向和明度，再决定是否进入实机切片/导入。
