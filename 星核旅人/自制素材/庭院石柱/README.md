# 庭院多立克石柱 · V4造型局部细化

## 交付范围

四张透明RGBA PNG为可供开发复制接入的源素材；不是新游戏功能。本目录不改Godot工程、不改变V4轮廓、不替换已认可造型。对应高柱52×108、断柱52×82、柱座52×24、倒落残段56×28。实际尺寸、alpha包围盒、锚点及文件SHA256见 `manifest.json`。

仅对原有不透明像素作局部RGB修改：浅槽局部单像素倒角与凹面深色、原裂纹短分叉与边缘、少量石片层理及断面小切面。无新符文、发光、柔光渐变、密集噪点、重复砖缝。不增加完整纵向槽，不重画外轮廓，不改柱粗、柱头、颈环和低圆基。保留左亮右暗的暖灰/紫褐大形。

## 开发接入

- PNG使用Nearest过滤、原始逻辑像素比例；避免平滑插值或单独缩窄柱身。不必将52px画布当作52px实体宽。
- `foot_anchor` 以画布左上为原点，x为画布中轴；y采用alpha bbox的bottom半开边界。高/断/座分别为 `(26,108)`、`(26,82)`、`(26,24)`；倒落为 **`(28,25)`，不是 `(28,28)`**，末3行透明。
- 非centered贴图的左上位置 = 目标接地点 − foot_anchor。Godot Sprite2D默认centered时，若节点直接放接地点，offset设置为 `canvas_size/2 − foot_anchor`；对应高柱 `(0,-54)`、断柱 `(0,-41)`、柱座 `(0,-12)`、倒落 `(0,-11)`。由开发按现有节点约定选择一种，不重复偏移。
- 预览严格复用V4摆位，包含原有地形遮挡；倒落在概念图的下缘原本被地形遮挡，不应机械把概念图top-left当无埋入的接地摆位。
- 仅装饰视觉输出；碰撞、遮挡层级、场景摆位及镜头缩放由开发另验。本交付未做Godot导入或实机测试。

## 复现与证据

在项目根目录运行：

```powershell
& 'D:\minic\envs\2024212971\python.exe' '自制素材\庭院石柱\generate_doric_assets.py'
& 'D:\minic\envs\2024212971\python.exe' '自制素材\庭院石柱\test_fidelity.py'
```

生成器只读取V4的 `column` / `fallen`，在内存中细化；原文件不改写。配景复用V4生成函数的隔离副本，仅替换柱子提供函数和输出文件名，保存至 `../庭院地面物件概念示意/concept_v5_detail.png`（640×280逻辑场景，NEAREST 2倍至1280×560）。保留原图标题及环境/人物/碑/碎石位置。

`fidelity_report.json` 记录：四图尺寸、逐像素alpha及透明RGB不变；四图RGB均有局部变化；两次生成PNG及manifest的SHA256一致；V4脚本、图片、说明哈希不变；预览差异只在四个原柱子矩形内。修改RGB像素分别为129/141/37/64，占可见像素5.05%/7.77%/6.75%/5.86%，alpha变化均为0。

已实际读取最终四张透明PNG及整景预览：圆柱明暗大形、独立柱头/颈环与低圆基保持，细节为稀疏局部变化，未形成密集木纹、脏斑或重复砖柱。此项为静态图美术复核，非实机可读性结论。
