# 第二关平台造型预览 V2（静态美术预览，尚未实装）

## 方向

把上层平台从“七段悬浮石条”改为**一座残存石拱渠／桥式平台**：

- 真实平台仍按原坐标：7 块走道石、2 个 8px 桥墩、5 个 8×6 实缝；
- 新增**非碰撞前景饰面**：连续雕花护墙、4 个桥墩立面（含 2 个纯装饰墩）、4 道拱券（最右一道断裂）、中央星徽嵌件；
- 5 个实缝**保留透空**，仅加 1px 内侧阴影，保证“石栅缝隙可施力”的读法；未把饰面当成新桥或新落脚面；
- 左高台、右短台用同一石作语言做轻量包装；右短台与主桥之间加一段**斜口断裂托石**，避免读成独立长凳。

**自绘**：护墙、拱券、桥墩雕面、星徽、高台/短台饰面、断裂托石。
**复用**：`基础场景原型/assets/map/ruin_platform_tiles.png`（地面与平台表面，逐像素按 `terrain_strip.gd` / `level02_block.gd` 重建）；`screenshots/ds03_godot_background_only.png` 背景；既有星核仓、石碑、出口门、主角帧（锚点与 V1 相同）。
**未复用**：V1 的 `draw_ground()` 与暖灰石砖地面。

## 几何与非碰撞边界

- 实际平台顶面仍为 **y264**，7 块走道石碰撞矩形不变；
- 5 个实缝仍为 `256..264 / 280..288 / 320..328 / 344..352 / 368..376`，y264..270；
- 2 个真实桥墩仍为 `232,264,8×36`、`296,264,8×36`；
- 2 个装饰桥墩位于 `332..340`、`372..380`，**无碰撞**，只是前景立面；
- 所有饰面 **y≤299**，低廊 20px 净空 **300..319** 完全未占用；地面与核的通行不变；
- 右短台真实顶面仍为 **y276**；斜口托石为饰面，顶边倾斜/断裂，不是新增台阶；
- 高台真实顶面仍为 **y274**；其雕面为饰面。

> 本预览没有新增任何碰撞、极性遮挡或可站立面。装饰桥墩/托石不代表可踩实体。
