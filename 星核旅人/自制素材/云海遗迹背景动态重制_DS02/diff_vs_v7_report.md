# DS02 对 V7 的静帧差异报告

- 对比：`reference.png`（640×360 逻辑） vs `background_only_v7.png` 的 640×360 最近邻结果。
- 差异：5,932 / 230,400 px（2.57%），最大通道差 53，bbox `[0, 234, 640, 341]`。
- 静态建筑 y<250 的保护区域差异：**0 px**。
- 保护文件：**35/35 哈希未变**（`checks/protected_hashes_check.json`）。

## 差异只来自以下几类

1. **云海重制**：V7 云海被重组成两块完整云体纹理（远/中 4.2 px/s、近 7.2 px/s，1278 px 真周期）。近层顶是平滑深度模型，不是逐像素复制 V7 近带边；接缝/云带边和阴影周围的像素因此变化。
2. **画外云延展**：左/右天空大云带各新增 56 px 画外云尾，t=0 时完全在画布外，不贡献可见差异；运动后会从画外进入。
3. **前景静态 overlay**：中央残拱/小残拱、右侧浮岛云底被单独画在运动云海之前，避免被云海误吞；它们使用 V7 像素，但叠放关系变化会改变少数边缘像素。
4. **投影**：新增中央/左下/低处三组浮石投影（扁平接触足迹、五档 alpha、source-atop 裁剪、随高度变位置/强度/1–2 px 尺寸）。
5. **清理**：底图在 y≥244 的非建筑区域清掉旧云海填充和低石下方残留小斑，避免运动时出现静态残影。

## 不声称的内容

- 不声称所有新像素都不可变；近层顶、云海接缝边、投影和 overlay 边缘都是本轮有意改动。
- 静态 5,932 px 差异不证明动效质量；动效另见 `preview.html`、`checks/time_trajectory.json`、`checks/seam_texture_*.png`、`checks/shadow_*_3heights.png`。
- 镜像是周期性重复，不是无限不重复云图；长看会看到左右对称。这是当前取舍，已在 README 写明。
