# 云海遗迹背景动态修复 DS03（美术拆层 / 隐藏补面 / 干净底图）

日期：2026-11-03。输入为已暂采用的 V2 静态图（用户“先这样吧”）；本目录只做美术拆层、必要隐藏补面和自审，**不实现最终动画、相位、时间、投影、离线 HTML 或 Godot 接入**。DS02 / V2 / V7 / Godot 全部只读，原 108 项哈希未变。

> 修订 DS03.1：G1/G2 的隐藏石面不再裁在 y=282，而是按 V6 原 `solid` 几何保留到 y=299（end 300）；y283–299 是桥体上浮的**不可见 reserve**，不加不透明矩形、不改拱洞。新增 `13` 号联合极值检查。参考叠图、可见建筑与右桥静态保真均保持原值。

## 1. 本轮解决什么

DS02 的根因已确认：`layers/island_overlay.png` 实际取的是右桥下部，里面混入了 V7 已烘焙的静态云色，又在 `sea_main` 之后盖回。结果是右桥下部不被厚云遮挡，云海移动时桥脚留下不动的白云块。

DS03 的修法：

1. 不再使用 `island_overlay`，也不把旧整背景回盖。
2. G1 左桥、G2 右桥同为 depth 30，**都在 `sea_main` 之前**绘制；两桥脚由同一层云海覆盖，右桥没有单独重盖的通道。
3. 底图只保留天空梯度 + 右后方极远静态残迹；桥、云、四组浮石、旧影都不在底图里，原位没有副本。
4. 右桥脚在 t=0 与 V2 逐像素一致（`455,205–560,282` 差异 0），所以不是靠改变静态外观来“修”；改变的是动态时的遮挡关系。

- **不允许**把 G2 或右桥任一段单独提到 `sea_main` 之后；那正是 DS02 的病根。

- `rock_remnants_static` 可省略；省略只会少掉 V2 里本来就静止的几块小石屑，不影响四组动体。

## 4. 拆层 / 补面口径

### G1 / G2 桥

- 几何：只读执行 `generate_background_v6.py` 的纯几何段（`layer/solid/left/right`），桥高、跨度、柱位、拱洞保持不变；完整墩体到 y=299，交付层保留到 **y=299（end 300）**。
- 可见像素：V2 可见石质像素逐像素照搬；包含 V2 的 818px 局部断口/接触影。没有恢复 V1 的通长砌缝/外圈高光/硬描。
- 隐藏面：被云色覆盖的墩/拱/梁像素按 V7 同一套石质调色还原；每列云顶以下到 y=299 用低对比石质空气色继续，**alpha 仍为 255**。原因是：如果补面做成半透明，云顶下沉时会露出天空，形成“透空鬼影”；实心低对比石面 + 云海前置遮挡才是正确的动态读法。
- **浮动 reserve（本轮修正）**：`sea_main` 顶边范围为 260–282。旧版把层裁到 y=282（end 283）：云顶最低 282 时，G1 上浮 1.5px 后底边到 281.5，会露 0.5 逻辑像素天空（整数取整 −2 时露 1px）。现在按 V6 原 `solid` 几何把 **y283–299** 一并保留为实体石面（G1 1581px、G2 561px，全部被云遮住），桥体底边为 298.5（浮点）/298（整数 −2）与 299（整数 −1），比最低云顶低 16–17px。该区**不是新增可见面**，也不加不透明矩形；拱洞照原几何保持透明。
- 右桥静态保真：`03` 参考叠图在 x455–560、y205–282 与 V2 差异 **0px**；新增 reserve 完全落在 `sea_main` 之后，t=0 时被覆盖，参考叠图与上一版逐像素一致。
- G1 补面 2530px（其中 1581px 为浮动 reserve）；G2 补面 752px（其中 561px 为 reserve）。两者都不含 8 种云海色（逐像素检查 0）。
- **右岛/断柱**：x474–482, y184–188 切空（45px），残柱顶 y189；岛底 5px 空气保留。被旧柱头盖住的岛底片段 42px 归 G5，避免 G5 隔离时出现矩形缺口。
- G2 没有被单独掏成“下部 overlay”；它是完整桥体，只是由前面的云海遮挡。

### G3 / G4 / G5 远建筑

- 全部为 V2 可见像素，不改轮廓、不加砖缝；对比度沿用 V2 的远景色阶（低于中景桥）。
- **G4 台基**：V2 里 x260–309, y206–217 的院落台基原先会被误当成“静态残石”；本轮归入 G4，随院落整体浮动，避免动态后留下原位副本。
- **G4 足部**：主桥面 y205 直接压住的列，把 y204 的 1px 天空线改成接触影（14px 可见，已解释）；y205–209 补在桥面后。断口凹槽里本来就能看见的足部不补，避免在断口里新增基座。
- **G4 台基右端**：被 `debris_central` 实际盖住的片段，用同一行左邻台基色补在岩石后（静止时完全不可见；浮石上移才露出）。
- **G5**：含小祠、平台、岩底，以及 x474–482 上方被旧柱头覆盖的岛底像素。该片段沿用 V2 柱头像素（浅色），没有重绘成暗色岩底，以免改变已认可的 5px 空气上方轮廓。

### 底图

- 只有天空梯度 + 极远静态残迹。没有桥、云海、天空云、四组浮石、投影或旧影。
- 天空梯度与 V2 的 `(45,90,112)→(120,165,174), y=315` 完全一致；y<130 与 V2 差异 0（参考叠图验证）。

## 5. 浮动建议（给 1 号工程）

- 中景桥：G1 ≤1.5px，G2 ≤1.0px；远遗迹：G3 ≤0.8px，G4 ≤0.6px，G5 ≤1.5px。建议周期 8.5–12s，不要用快速抖动。
- **桥脚浮动余量**：G1/G2 的墩体已补到 y=299（end 300）。`sea_main` 云顶最低 282 时，G1 上浮 1.5px（整数 −2）桥体底边 298、G2 上浮 1.0px（整数 −1）底边 299，仍有 **16–17px** 重叠；不需要减小上浮幅度，也不需要改云位移。工程按最多 1.5px/1.0px 上浮即可。
- **G5/G2 安全幅度**：静止空气 5px。G5 1.5 + G2 1.0 的任意相位相对位移 ≤2.5px；整数取整的最坏情况（G5 +2 / G2 −1）仍剩 **2px** 空气。更稳的做法是 G5 与 G2 同周期同相（相对 ≤0.5px，空气基本保持 4.5–5.5px）。若工程要把 G2 提到 1.5px，必须同相，或把 `|dyG5 − dyG2|` 限制在 ≤3px。
- **G3/G1**：G3 岛底 y199 与左桥面 y205 静止 5px；G3 0.8 + G1 1.5 的相对极值 2.3px，最小 2.7px，无接触。
- **大组内部不要拆**：G1 的桥面/横梁/柱/拱/墩同图；G2 的残柱与桥体同图；G5 的小祠/平台/岩底同图；G4 的台基与院落同图。
- **不要**把 G3/G4/G5 拆成“建筑 + 云底座”。云底座不在这些图里，桥脚/岛脚的云全部由 DS02 的 `sea_main/sea_near` 提供。
- 建议让 G1/G2 同相或相近相，避免两桥一上一下；G5 与 G2 若独立相位，按上面的极值限幅。
