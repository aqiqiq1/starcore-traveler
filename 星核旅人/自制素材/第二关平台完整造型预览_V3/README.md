# 第二关平台完整造型预览 V3（静态美术提案，尚未实装）

## 这版做了什么

把 V2 的“褐色碎块压在雕花条上 + 四个小断拱”改成**一座连续的双拱古渠桥残段**：

- 主平台 `232..400`：顶面从 232 到 399 **一条连续石质顶缘**；桥身一块连续体，只开 **2 个大拱**（`246..294`、`314..368`，拱顶 y283），中间 1 个宽墩（`294..314`，盖住真实 296..304 墩）。
- 左端 `232..246`、右端 `368..400` 为实体桥台，端部有明确檐口、隅石和收口阴影。
- 右短台 `400..432` 顶面仍为 y276，立面与右桥台接到同一底层 y299，形成**同一右端下行结构**；没有新增任何平坦可站顶面。
- 左高台 `152..208` 顶面仍为 y274，用同一套檐口/隅石/底部线，底部做**有意的两级叠涩收分**（不是随机破口）；`208..232` 的 24px 跳跃空隙保持空。
- 五个真实 8×6 缝在视觉上被连续桥面盖住；桥面饰带只在缝中心留 1px 低调嵌缝作为提示，不露洞。
- 装饰只保留：3 条桥面石板缝、5 条嵌缝、少量苔痕/水渍/麻点。没有小徽章、重复碎花、四联小拱、碎边。
