# 守望者残响：素材与权属说明

## 1. 身份与用途

- 显示称呼：**守望者残响**。
- 用途：第一关两处固定显现的同一个古代守望者残影；开发后续把原 `(250,300)` 与 `(735,300)` 两处石碑替换为同一残响的两次显现。第二关石碑保留。
- 本素材只提供 **48×64 的 idle 帧**，不包含行走、战斗、头像、大立绘、寻路或对话系统；也不包含 scene/script 改动。

## 2. 规格

- 帧表：`guide_echo_idle_4f.png`，**192×64**，横排 4 帧，每帧 **48×64**。
- 单帧画布：48×64；脚底锚 **（24,60）**。
- 实际 bbox（含半透明残片）：
  - 帧0：`[11,14,38,58]`
  - 帧1：`[11,13,38,57]`
  - 帧2：`[10,14,38,58]`
  - 帧3：`[10,13,38,57]`
- 主可见轮廓约 **x10..37，y13..57**；最低残片在 y57，距脚底锚约 3px，保留微悬空。头顶在 y13/14，留有气口。
- 颜色：灰白石色 + 低饱和淡紫 + 少量暖面部高光；无大面积金/青，无主角红围巾色，无霓虹扫描条/屏幕。
- 动画：帧1/3 整体上移 **1px** 作呼吸；帧2/3 交替少量边缘残片 alpha/位置。面部和主体保持清楚，不通过整体大幅透明闪烁偷动画。

## 3. 权属与生成方式（必须保留）

- 本素材是**为本项目新绘制的本地像素派生素材**，由 Python Pillow 逐像素绘制，AI 辅助排布与调色。
- **不是人类手绘**；不得在交付、展示或课程材料中声称是人类手绘。
- **角色像素图没有使用第三方图像或生成服务**；未下载、未购买、未上传、未调用付费生成服务。审查预览的 “1x native / 3x NEAREST” 标签使用了项目已有 **Fusion Pixel 12px** 字体（OFL-1.1），该字体只用于预览文字，不进入角色帧表，也不改变角色本身的权属说明。
- 不得冒充任何第三方作者、原作或许可；本文件即为权属说明。最终视觉仍由协调者验收。
- 设计方向来自本项目 `docs/WORLD_LORE_AND_GUIDE.md` 第5节与用户确认，不是对既有第三方角色的复刻。

## 4. 接入注意

- 运行时只用 `基础场景原型/assets/guide_echo_20261112/guide_echo_idle_4f.png`。每帧按 48×64 切分，保持 Nearest、整数坐标；不要缩放或平滑过滤。
- 以脚底锚（24,60）对齐地面/显现点；每帧画布原点一致，帧间不重新裁切。
- 不依赖 Godot 自绘身体；不要给 NPC 加实体碰撞、寻路、跟随或跨断桥移动。
- 两处显现点是同一残响的两次固定显现，不解释成两个 NPC；第二关石碑不替换。
- `guide_echo_preview.png` 只供审查，不是 runtime 贴图；它包含同一原生单帧的 1x 与 3x NEAREST 对照，**不是引擎截图**。
