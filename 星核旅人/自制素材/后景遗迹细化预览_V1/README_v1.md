## 具体细化点

1. **左断桥**：桥板加两道通长层缝、错缝竖砌与檐下影；墩面左缘受光、右缘背光，少量竖向风化；两拱外缘 1px 倒角；桥板断口集中外露砌块、断口亮边与下缘影；柱头下影、柱身左缘受光；残柱断口。
2. **右断桥**：同一套桥板层缝/错缝/檐下影；左右墩倒角；拱券外缘受光；右桥板断头加集中砌块截面与阴影；右横梁阶梯残端补 1px 亮/影；柱头与残柱断口。桥高、跨度、拱厚、支撑位置未改。
3. **左端残厅/浮岛**：柱身鼓段与柱头下影、墙身层缝/错缝、连续石檐下缘影；不扩大岛体轮廓。
4. **左后远院落**：塔身亮/暗面、两道层缝与错缝、断顶；门拱外缘受光、内壁影、三道低对比券缝与锁石（洞口天空不落笔）；右残墙层缝；台基前缘受光。
5. **右浮岛/小祠**：檐口亮/影、墙角、门洞内壁、附屋压顶；岛台前缘 1px 受光、错缝与檐下影；下缘只加 3 段迎光、2 段背光，保留原岩面转折。
6. **云中残拱**：只在两足加 4 条 1px 受光/影，冠部与整体轮廓不动。

细节都控制在 1–2px 的冷色阶内；远建筑比桥体更淡，保留空气透视。没有新增建筑群、柱列、桥段，也没有改云/浮石的位置形状。
