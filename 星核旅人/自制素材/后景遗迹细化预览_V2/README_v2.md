## 相对 V1 删了什么

V1 的问题是“把近景的读法贴到远景”，V2 从 V7 重新派生，以下 V1 笔触不再保留：

1. 桥面两道通长横缝、密集错缝竖线和柱头下的第二道横带——不再把桥板画成两层砖墙。
2. 拱券外圈连续高光——不再给拱洞加“贴纸描边”；V7 原有券石分缝和券厚保留。
3. 桥墩左右缘通长竖线（尤其是一直伸进渐隐下段的深竖线）——全部删去，墩脚只保留 V7 的云前渐隐。
4. 左后远院落的塔身格子、墙面砖缝、拱券外圈和台基亮线——不再逐块刻砖。
5. 右浮岛平台的通长横带、竖缝和“L”形下缘暗线——不再把岛台画成桥面。
6. 左桥断口的亮色砌块、右横梁端面的亮线——断口不再用随机小砖和亮块解释。

## 结构 / 遮挡改了什么

1. **右浮岛与断柱脱开（本版最关键）**：V7 里岛底 y183 与断柱顶 y184 硬接，读成“柱顶着岛”。V2 在 x474–482、y184–188 切出 5px 天空，断柱顶下移到 y189，并重做 2px 断口（左半受光、右半背光）。岛的整体轮廓、位置、桥面高度/跨度、柱位均未改；只局部缩短了这根残柱，并让它露出独立断口。这是静态遮挡修正，不是动态方案。
2. **桥墩不再硬描**：只在墩顶 y220 加 1px 檐下接触影；不再向下画边线。V7 原有的墩面砌缝和云前渐隐保留，细节自然消失在云里。
3. **断口按受光方向读厚度**：左桥板断头朝右=背光，压 1px 断面、点朝上小台阶；右桥板断头朝左=受光，做 1px 受光断面；右横梁端面朝右=压暗。断裂集中在破口，不再散落随机砖块。
4. **远遗迹只读大形体**：左端残厅、左后远院落、右浮岛各用 1–2px 的顶面受光 + 左右大面微差；门洞内侧右侧压 1px 影交代拱厚。没有新增砖缝、格子、外圈描边，也没有移动建筑或新增体块。

## 景深如何拉开

- **中景断桥**：保留最强的局部对比和清晰的桥板/拱券/梁柱轮廓；细节只服务受力与断口。
- **远景三处遗迹**：色阶以当地像素为基准做 ±4%–9% 微调，始终贴近天空色；只保留柱、门洞、岛台的大形，不加微细节。远遗迹不再比桥更抢眼。
- **桥脚**：不在渐隐区落任何固定深色；所有色阶随当地 V7 像素变化，因而随深度自然衰减。
- **右浮岛**：以 5px 空气和更淡的体块与近处断柱分开；断柱保持较深、较实的近景值。
- **未改**：天空、云海、天空云、游离浮石、云中残拱均未动；云中残拱保留 V7 原岩石/遗迹质感。

## 自审与未验证

已实际打开并检查：640 逻辑图、1280 主图、以及 5×/12× 的右浮岛接触、右墩脚、左桥断口、远院落、左端残厅局部。检查结论：

- 右浮岛与断柱之间有可见空气，断柱顶是独立断口，640 下不再读成“柱顶托岛”；但 5px 间隙在更小显示尺寸下是否仍够清楚，未做实机/人物合成验证。
- 桥墩下段没有新增硬竖线；细节在 y238 后淡出，未出现 V1 的硬直切口。
- 远遗迹的局部对比明显低于断桥，未出现 V1 的格子贴纸感；但“结构是否够清楚”仍需用户按主预览判断。
- 若用户仍觉得岛像被柱托住，下一步应讨论岛/柱的组合关系或更大脱开，而不是整体再淡一遍；那会动到批准轮廓，需协调者确认后再做。

**仍未做**：浮动/视差/遮挡补面；桥后与云后不可见建筑面；DS02 的左右断桥遮挡和右桥下静止白云；Godot 接入与引擎截图；人物/前景/文字/UI 合成检查。V2 的 5px 间隙只保证静态读法，未来成组平移时柱（G2）与岛（G5）的相对位移、间隙变化和隐藏面都未验证。
