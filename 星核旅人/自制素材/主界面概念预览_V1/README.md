### 视觉取向

- 冷青白昼云海、风化古遗迹；UI 不压暗整张白昼画面。
- 浅象牙字 + 深青石质折角按钮；金色只作为开始入口的细内线（选中/护符式点缀），冷青只用于短分隔线与音量符号。
- 开始入口有实体石牌与更高对比；设置入口无底板、字重更轻，保持安静。
- 不使用现代网页圆角卡片、玻璃拟态大面板、霓虹科幻、满屏厚黑底或大花纹遮景；云、桥、遗迹仍保留呼吸空间。
