# 本轮改动验收清单（2026-11-27）

给主人统一看用。按“点哪里 → 看什么”写，不按代码文件写。

## 怎么开始

1. 标题页：只有 **开始游戏 / 章节 / 设置 / 退出游戏** 四行。
2. 点 **章节**：6 行，未解锁置灰并写「需先完成 X」；默认只开断桥庭院。
3. 点 **开始游戏**：从第一个没通关的章节开始（新档就是 L1）。

## 本体

**L1 断桥庭院**
- 渐黑进场：点开始后整屏黑，**0–2.5 s 纯黑无白点**，之后才有 20 颗暖金浮尘。
- 开场：地震抖动 + 闷响 → 主角从右缘踉跄入画 → 退半步、左右看、头顶「？」→ 触碰石碑 → 残响半透明显形。
- 残响第一页：「别怕。他们叫我守望者残响。守桥的人早就没了——你听见的，只是他留下的那点回声。」
- 星核到手后：镜头 1 s 拉回 → 黑边收 → HUD 淡入 → 站定 → 才给控制（接管第一下不会误跳/误换相）。
- 出口前有一道 **同相门**（只认澜相/月），错相会提示按 Q。

**L2 沉寂回廊**
- 出生点到第一个联动仓之间有一道 **反转紫幕**：穿过翻一次相，提示「紫幕翻相 · 按 Q 换回来」；站着不动不会连续翻。

**L3 断桥外郭**
- 结算：**「第三关完成 · 用时 mm:ss」**，按钮「重玩本关 / 返回主界面」；DLC3 存在时多一个 **「进入城内」**，可以直接进第四关（星核织机）。

## DLC

**DLC1 星核试炼场**
- 开场：**真实那道门**近景（太阳牌、挂锁、光幕）→ 金/青晶体依次亮 → 门锁转、门缝光落地 → 拉回玩家。
- 没有“封印青晶体”那种看不懂的东西了；广角帧里金门、金晶体、青门同框。
- 暂停页有「操作」表（六行，12 px）。

**DLC2 裂隙工坊**
- 整章是**室内工坊**：暗木梁、铁链、炉火、石地；镜厅三拱有内层砖与齿轮剪影，不再是黑洞。
- 开场：真实镜厅 → 双面镜睁眼、金/青面盘亮 → 相位波扫真实地面 → 左移回入口主角。
- 第一道月门前有 **星核运送**：靠紫幕翻相推/拉星核进仓，仓亮 → 导线亮 → 门开；拉出断电关门。
- 三阶段两次连射：预警 0.65 s、中间 0.12 s 空档；裂纹在面盘下面，转起来不再被盖。
- 暂停页有「操作」表，边框 2 px。

**DLC3 星核织机**
- 开场：真实织机厅 → 三排顶灯逐亮 → 4 帧梭子滑过 → 两侧节点+核心点燃 → 拉回玩家。
- 入口：同相门（需辉相）→ 星核推入星核仓开第二道月门 → 检查点。
- Boss 战：阶段 1 第一轮就会召唤紫色浮灵（一只、一击可清）。
- Boss 条：红条 3 段核心耐久；菱形只表示两个节点；条下 3 颗命心。

## 全局

- Boss 条六章同款：红条 = 核心耐久（分段），菱形只给独立对象（双面盘/织机节点），阶段用小格。
- 暂停页六章同款：四命令 + 「操作」表；结算页六章都有用时，按钮统一「重玩本关」。
- 换相音效两种：升相 / 落相。
- 星核：12 帧有切面/内芯/金环；星核仓：石座 + 铜框 + 玻璃，空仓暗、入仓从内部亮起。
