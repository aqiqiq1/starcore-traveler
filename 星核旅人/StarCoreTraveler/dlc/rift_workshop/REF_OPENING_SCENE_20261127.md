## 2. 实际看到的连续顺序

1. **0.0–2.25 s**：主角在真实石廊里向右移动，画面始终保留砖墙、红色旗帜、壁灯、青雾和地面植被。镜头跟人，没有切到黑底，也没有把房间替换成一张背景图。
2. **2.25–2.5 s**：画面短暂压暗，进入同一关卡的 Boss 房间；房间的火把、石柱、拱洞和旗帜继续作为实体空间存在。
3. **2.5–5.5 s**：Boss 单独占据画面中心，主角不在镜头里；顶部出现大号 Boss 名「The Incomplete One」。约 3.0–3.5 s 有白色环形脉冲围着 Boss，Boss 同时做出仰身/吼叫动作。房间并没有变黑，只是把注意力集中到 Boss。
4. **5.5–7.0 s**：名字淡出；Boss 的地面火焰攻击发生；主角从画面右缘进入**同一个真实房间**，随后镜头里同时有 Boss、主角、火焰和地面。
5. **7.0–10.2 s**：正常战斗。主角和 Boss 共用同一套房间几何与光照，Boss 的体型、颜色和攻击特效是唯一的高亮层。

## 3. 能借鉴 / 不能照搬

能借鉴：

- Boss 出场先给**真实房间里的 Boss**，不是另绘一张黑底插画；房间结构、灯火和地面始终在。
- 用取景把主角暂时移出画面，让 Boss 独享一个短 beat；再用真实主角回到同一空间，完成「先 Boss、后主角」的注意力移交。
- 一个 beat 只讲一件事：先亮相/名号，再动作脉冲，再回到玩家。我们的分镜对应为「挂镜与闭眼 → 睁眼/面盘亮 → 地面相位波 → 拉回主角」。
- Boss 的轮廓、动作和局部特效是画面里最亮、最饱和的部分；房间只做低饱和承托。

不能照搬：

- 「The Incomplete One」名号、Concierge 造型/姿态、火焰攻击、石廊的火把/旗帜/拱洞具体布局、配色和像素。
- 原作的房间切镜节奏和 UI 字体；我们的 640×360 工坊有自己的双面镜、金/青面盘和链挂结构。
- 原视频是**房间式切镜/压暗进入**，不是连续横移。本任务要求「向左拉回」，所以我们的连续 Camera2D 横移是**按任务要求的改编**，不能写成「死亡细胞原样如此」。

## 4. 与本次实现的对应

- 真实场景：`RiftWorkshop` 的 `Background/Back|Mid|Fore`、`RiftFloor`、`Player`、`MirrorBoss` 都保留；开场只新增真实的 `OpeningCamera2D`、世界坐标的眼睛/面盘光/地面波覆盖层，以及屏幕暗调和跳过提示。
- 镜头：0.0–2.6 s 停在真实镜厅（Boss 在画面中心）；2.6–3.8 s 沿真实房间向左横移到 x=40 的主角；3.8–4.0 s 停在主角的玩法取景。
- 暗调：开场用屏幕暗调把房间压暗，但从 0.30 s 起就保留石墙/窗/链的可读性，不回到黑底。
- 参考限制：视频只用于观察「真实房间 + Boss 聚焦 + 回到玩家」的关系；没有把任何帧作为运行素材。
