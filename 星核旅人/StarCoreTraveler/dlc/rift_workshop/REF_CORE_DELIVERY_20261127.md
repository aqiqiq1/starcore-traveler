## 3. 从参考落到本轮规格

1. **共享组件**：把 DLC3 的 carrier/bay/proxy 移到
   `dlc/shared/core_delivery/`，DLC2 与 DLC3 共用一份实现；DLC2 只通过
   `field_range_override` / 半径覆盖做本章调参，默认 `-1` 保持 DLC3 原值。
2. **位置**：星核起点 x=200、地面前后范围 x=188–244、仓 x=244、月门 x=270；
   全部在紫幕 x=160 与月门之间。仓的短导线朝右接门；星核/仓都在地面
   y=304/320，不挡门上方的日/月徽记和人物头部。
3. **解法**：出生辉相 → 穿过紫幕变澜相 → 同相把星核推向仓（仓亮、导线亮、
   门开）；走回紫幕变辉相 → 异相把星核拉出仓（仓暗、门关）；再穿紫幕变回
   澜相即可推回，无软锁。运送组件在星核入仓且玩家在右侧时会夹住星核，因此
   过门后不能从远侧把核拉出。
4. **HUD**：目标行从开场就写“送星核入仓，为月门供电”；入仓事件
   “星核入仓 · 第一道门通电开启”，离仓“星核离仓 · 第一道门断电关闭”；
   未供电时撞门“第一道门断电 · 把星核送进仓里”。事件行不替代仓/门的画面状态。
5. **不新增**：没有新动作、没有解锁 Q、没有改 Boss/桥/光灵/反转场；星核与仓
   无碰撞体，不能夹人、顶飞或当踏板。
