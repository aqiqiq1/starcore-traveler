# 关卡选择判断 + 第四关接入准备（2026-11-27）

状态标记：**已定** = 本轮按此执行；**提案** = 待主人确认后才动工；**未做** = 明确不做。

## 1. 关卡选择：不做完整版（已定）

理由：

1. 四关是**线性叙事**（断桥庭院 → 沉寂回廊 → 断桥外郭 → 城内/织机），关卡之间靠“送核入城”一条线串起来；做网格选关会把这条线拆成互不相干的入口。
2. 教学顺序是设计的一部分：L1 教相性、L2 教导相与锁、L3 教守卫与门、DLC 各自补一套机制。自由选关会让玩家跳过前置教学，然后在 DLC 里卡住。
3. 标题页现有三行 DLC 预览已经承担了“直达”的功能，再叠一层选关页是重复导航，也多一套解锁状态要维护。

具体做法：

- 标题页三行 DLC 保持现状：可看简介、可直达（已解锁时）。
- 第三关完成页在 `star_loom` 存在时多一个按钮：**进入城内** → 直接进第四关；没有该场景时只显示原本的“回到标题”。
- 第四关完成 → 结尾页 → 回标题。
- 全通后如果还想要“回看”，加一个**章节回顾**小页（只读：标题/用时/截图），不进主流程；**未做**，等主线稳定后再议。

## 2. 第四关怎么接（已定方向，未接线）

- `dlc/star_loom/star_loom.tscn` 就是**第四关的 Boss 房原型**，继续留在 DLC 独立目录，不复制资源。
- 将来新建 `scenes/level_04.tscn` 时只做两件事：入城走廊/前厅 + 在流程里引用 `star_loom` 作为后半段。两条路都行，优先 A：
  - **A（推荐）**：`level_04` 自己是一段短走廊，走廊尽头用 `change_scene_to_file("res://dlc/star_loom/star_loom.tscn")` 进 Boss 房；`star_loom` 完成后回 `level_04` 的结尾页。
  - **B**：`level_04` 直接实例化 `star_loom` 作为子场景，存档点与相机要重接，改动大，暂不选。
- 接线时必须同时改的四处：`level_03` 完成页按钮、`LevelFlow` 的场景常量、标题页的“继续”、以及 `star_loom` 的完成页去向。缺一处就会出现“能进不能出”。
- 本轮**不接线**：`level_03` 完成页仍只回标题，`star_loom` 仍从标题/DLC 直达进入。
