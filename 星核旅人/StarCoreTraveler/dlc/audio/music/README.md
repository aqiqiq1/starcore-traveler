## 设计说明

### trial_ambience — 试炼场 / 石造回廊

- **目标**：安静、神秘、低密度，不压过对白。
- **写法**：D 小调持续 drone（D1/D2/A2/D3，轻微失谐慢拍）；Dm(add9) 开放排列和声垫（F3/A3/D4）；两层去相关的空气噪声与一层 4.2 kHz 高频空气；5 次石质模态共鸣（D3/A3/F3/D4/A3，5.5–7.5 s 长尾）；40.5/45.2/50.6 s 的三音远影（D4–F4–E4，极轻、无节奏）；12/44 s 两次极轻低频心跳；30–58 s 高空微光（A4/E5）。
- **结构**：前 16 s 事件最少（0.4 s 有一次石鸣）；16.6 s 第二次石头共鸣；30–58 s 微光渐入渐出；57.9 s 最后一次石头尾音绕回 0 s。没有主导旋律，1–4 kHz 刻意留白给对白。
- **混音**：低频与低中频是主体，2–8 kHz 频段约 -38 dBFS；单声道相关度 0.53，适合游戏总线。

### rift_ambience — 裂隙工坊

- **目标**：空气感、紫色/低频脉动、轻微不安。
- **写法**：F 小调，F1/F2/C3 长音上加很轻的 B2 三全音；Fm7 模糊和声垫（F/Ab/C/Eb，叠 B♮）；4.2 kHz 与 6.5 kHz 两层空气噪声；7 个稀疏 FM 金属点；32–60 s 的 F5/Ab5/C6 高空微光；低频心跳在 A/C 段每 2 小节一次、B 段每小节一次；每 4 小节一次极轻的机械气流。
- **结构**：三段各 8 小节：0–26.67 s（A，最疏）、26.67–53.33 s（B，心跳加密、金属点变多）、53.33–80 s（C，退回空气层）。
- **混音**：高频空气频段约 -39.7 dBFS，低频脉冲是峰值来源；单声道相关度 0.59。

### loom_boss — 星核织机 BOSS

- **目标**：节奏明确、紧张但不刺耳，可长时间循环。
- **写法**：D 弗里几亚，140 BPM，4/4。4/4 kick（B/C 段加切分重音）；2、4 拍军鼓 + 16 分 ghost；8/16 分闭镲；16 分贝斯 ostinato（D/Eb/C/Bb/A/G）；tom 与机械 tick；带八分音符开合的“织机气声”；四音细胞动机 D4–F4–Eb4–D4（附点八分延迟、左右交替）；稀疏 FM 金属织机点；两小节噪声上扬与军鼓滚奏做段落转折。
- **结构**：A 0–20.57 s（建立）、B 20.57–41.14 s（加密、转调色彩）、C 41.14–61.71 s（高潮）。每段最后 2 小节（0-indexed 10–11、22–23、34–35）有 fill；最后 2 小节 turnaround 收在低音与军鼓滚奏上，直接接回第 1 小节。3 段式，但 loop 点按“下一小节”处理，不靠淡出。
- **混音**：总线压缩（-20 dB 阈值、4:1、4 ms 包络、6 ms 平滑）+ 轻饱和；峰值 -8.05 dBFS，RMS 比两首环境曲高约 1.4–3.9 dB，进入战斗时更靠前。

## 生成方式

- 环境：`D:/minic/envs/2024212971/python.exe`（Python 3.13.7），numpy 2.3.3、scipy 1.18.1、soundfile 0.13.1 / libsndfile 1.2.2。
- 命令：

```powershell
D:/minic/envs/2024212971/python.exe tools/generate_music.py all
D:/minic/envs/2024212971/python.exe tools/analyze_music.py
```

- 所有声音由脚本合成：加法合成 pad、模态合成石鸣、正弦/锯齿低音、FM 金属点、噪声整形、合成混响 IR。**没有使用任何外部采样、循环包、预设或第三方 IR**。
- 循环做法：
  1. 每首曲子长度是精确的整数小节（64.000 / 80.000 / 61.714 s）；
  2. 所有持续音与 LFO 的频率吸附到 `1/loop_length` 的整数倍，保证整数周期；
  3. 所有一次性音符越界时“环绕叠加”到文件开头；
  4. 混响使用频域循环卷积，尾音跨过循环点也不会被切断；
  5. 文件首尾不做淡入淡出，靠波形本身的周期性闭合。
- 峰值统一归一化到 -8.0 dBFS；OGG 解码后实测 -7.72 / -7.72 / -8.05 dBFS，真峰值近似值 -7.72 / -7.67 / -8.04 dBFS，均在 -6～-9 dBFS 范围内，无削波。

## 循环点

- 每首文件本身就是**一个完整循环**：`loop_start = 0.0`，`loop_end = duration`（2,822,400 / 3,528,000 / 2,721,600 samples）。
- OGG Vorbis 没有标准的循环点元数据。Godot 导入时：
  1. 选中 `.ogg`，在 Import 面板勾选 **Loop**；
  2. `Loop Offset` 保持 0，`BPM`/`Beat Count` 可留空；
  3. 不要 Trim，也不要额外加首尾静音；
  4. 重新导入后 `AudioStreamOggVorbis.loop` 即为 `true`。
- 本次没有改动 Godot 自动生成的 `.import` 设置（默认 `loop=false`），避免越界修改工程导入配置；如果希望资源默认循环，把对应 `.import` 里的 `loop=false` 改为 `loop=true` 即可。

## 试听建议

1. **trial_ambience**：用较低音量循环 3 次以上。注意 0.4 s 的第一次石鸣、57.9 s 最后一次石鸣的尾音是否自然绕回开头；确认对白/环境音下不会抢中频。
2. **rift_ambience**：耳机与小音箱各听一遍。检查 40–60 Hz 心跳是否在小音箱上过重；在 80 s 接缝处听是否有“咔”声（测量上无异常，但仍建议人耳确认）；高频空气应位于音效后方。
3. **loom_boss**：以游戏内战斗音量听。检查 140 BPM 的 16 分贝斯是否清晰、20.57/41.14 s 的段落转折是否有推进、61.71 s 接回 0 s 时第 1 小节 downbeat 是否明确；军鼓/闭镲在高音量下不应刺耳。
