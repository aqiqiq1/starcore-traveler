## 1. mirror_boss.ogg — 镜面 Boss 战

**结构**：36 小节 @ 128 BPM，每小节 1.875 s，共 67.5 s（2 976 750 样点，正好整数小节）。
和声为 4 小节循环 Dm – B♭ – Gm – A。

| 小节 | 时间 | 内容 |
|---|---|---|
| 1–4 | 0.0–7.5 s | 节奏组直接从第 1 小节进入（不做冷开场），铜质短句 + 玻璃回应 |
| 5–12 | 7.5–22.5 s | A 段：铜质主题句，第 9 小节起玻璃钟高八度镜像回答 |
| 13–20 | 22.5–37.5 s | B 段：两面交换声像，玻璃接过主旋律，铜做低音长音对位 |
| 21–28 | 37.5–52.5 s | 推进段：两小节为单位逐级上行，25 小节起 16 分音符脉冲与跑动 |
| 29–32 | 52.5–60.0 s | 半速喘息：脉冲减半，金/青一小节一次对话，铺底最厚 |
| 33–36 | 60.0–67.5 s | 收束 + 第 36 小节第 4 拍过门，属音钟声跨过循环点 |

**低音脉冲**：8 分音符正弦 + 0.14 倍次八度 + 0.22 倍二次谐波，`tanh` 驱动，
3.5 ms 起音、0.24 s 包络。铺底与和声垫在每个脉冲下压低 4 dB（包络 120 ms 释放），
所以小音量下脉冲仍然读得出来。

**两个音色（金/青）**：
- 暖铜板：加性合成，分音比 1 / 2 / 3 / 4.02 / 5.42 / 7.13，衰减 0.55–0.09 s，
  另加 12 ms 带通噪声作为槌击边；
- 玻璃钟：强非谐分音 1 / 2.756 / 5.404 / 8.933 / 13.34 / 18.64，衰减 1.1–0.10 s；
- 金属敲击：1 / 2.32 / 3.87 / 5.43 / 7.11 / 9.62 短衰减 + 8 ms 撞击噪声；
- 玻璃碎片：高频短鸣 + 5–14 kHz 噪声瞬态。

**镜像手法**：A 段铜在左（-0.42）、玻璃在右（+0.44）；B 段两者交换声像。
主题句本身不上移，而是把同一动机交给另一面演奏，靠声像与音色完成"镜像"。

**循环点做法**：
1. 所有事件按 36 小节网格排布，事件时间不取模，超出末端的余响在混音时**按 N 取模折回开头**；
2. 混响用一次卷积（程序化 IR，2.9 s），卷积结果末尾的尾巴同样折回开头；
3. 母带链（去直流、28 Hz 高通、200 Hz 分频展宽、压缩）全部按**环形稳态**处理：
   把信号接成 3 份、滤波后取中间一份，避免滤波器在 0 点从零状态启动造成的接缝台阶；
4. 第 36 小节第 4 拍写满过门（4 个 16 分金属边击 + 低音 + 底鼓），并对上一小节属音钟声，
   使循环点落在乐句内部而不是空白处。

**实测接缝**：

```powershell
& $py -c "import soundfile as sf, numpy as np, sys; y,_=sf.read(sys.argv[1], always_2d=True); d=np.abs(np.diff(y[:,0])); print('seam', abs(y[0,0]-y[-1,0]), 'p99.9', np.percentile(d,99.9), 'max', d.max())" "dlc/rift_workshop/assets/audio/mirror_boss.ogg"
```

```
seam 0.021144 p99.9 0.043757 max 0.112468
```

接缝处相邻样点差 0.0211，**小于全曲相邻样点差的 99.9 分位（0.0438）**，即循环点不比任何一个
鼓点起音更"陡"。另外把接缝的 5 ms 前后电平差与全曲 35 个小节线对比：

```
seam pre/post delta +4.85 dB；全曲小节线中位数 +14.33 dB（范围 +9.12…+18.12）
```

循环点的电平跳变只有普通小节线的 1/3，说明第 36 小节到第 1 小节是连续的乐句进行。
（这两项是可测量的连续性证据；是否听不出接缝仍需人耳确认，见文末。）

## 3. title_theme.ogg — 云海断桥（标题）

**结构**：16 小节 @ 72 BPM，每小节 3.3333 s，共 53.3333 s（2 352 000 样点）。
A 大调，和声 Aadd9 – F♯m11 – Dmaj9 – Esus4 循环三次，13–16 小节改为 Bm9 – D/E – Aadd9 – Aadd9
（vi – IV/V – I），把结尾收在持续的主和弦上。

**动机**（4 小节，钢片琴）：A4 – C♯5 – E5 ｜ F♯5 – E5 – C♯5 – B4 ｜ A4 – B4 – C♯5 – E5 ｜ D5 – C♯5 – B4。
第 5、9、13 小节出现三次：第 9 小节加三度副旋律与低音线，第 13 小节收薄并停在 B4（挂留），
回到循环开头的 A 和弦解决。

**音色**：钢片琴式击弦（基频 + 2 / 4 / 9 分音，8 ms 起音、0.55 s 衰减）；
玻璃高音（1 / 2.756 / 5.404）；8 谐波 × 3 组 ±6 音分去谐的柔和铺底（低通 1.3–1.9 kHz）；
A1 持续低音；"云海"用环形噪声（DFT 网格生成，天生周期）做 250 Hz–4 kHz 钟形滤波 +
慢速振幅起伏；两声木头吱呀（150–210 Hz 窄带噪声 + 慢摆动）。**没有任何鼓或低频脉冲。**

**循环点做法**：环形噪声与混响尾巴同样折回；母带链环形处理；第 16 小节末尾的高音钟
与 Aadd9 铺底跨过循环点。

**实测接缝**：`seam 0.013271 / p99.9 0.038241 / max 0.067971`；
接缝 5 ms 前后电平差 +4.94 dB，全曲 14 个小节线中位数 +4.42 dB（范围 -5.36…+10.78）。
循环点与普通小节线同量级，没有额外跳变。

## 4. polarity_switch_v2.wav — 极性翻转

0.40 s，单声道 16-bit（与 `rift_workshop/assets/audio/` 下其他 SFX 的格式一致）。

**读法**：G4（392 Hz）先立住 115 ms，然后音高沿 S 曲线在 75 ms 内滑到 D5（587.33 Hz，纯五度），
滑行段用**反向包络**（渐强推进）而不是正常衰减，交接处补一枚 2.64 / 3.95 kHz 的玻璃点，
之后 D5 以玻璃质感（加 2.756 / 5.404 非谐分音）余音收掉。

不是 UI click 的原因：4 ms 起音、无宽带瞬态、有明确音高轨迹与和声关系（五度），
能量集中在 250 Hz–2 kHz（实测 99.8%），而不是点击声典型的 3–8 kHz 宽带。

## 5. polarity_switch_moon_v2.wav — 落相

### 手势：不是倒放，是“敲在顶上再掉下来”

| | 升相 `polarity_switch_v2.wav` | 落相 `polarity_switch_moon_v2.wav` |
|---|---|---|
| 起手 | G4 驻留 115 ms，正常衰减 | D5 敲响并驻留 30 ms，4 ms 起音 |
| 中段 | 120–150 ms 音量凹口，然后**反向包络渐强** | 115 ms 内从 D5 落到 G4（快起慢收的“重力”曲线） |
| 落点 | 75 ms 滑到 D5，接玻璃点 2.64 / 3.95 kHz | G4 落位触点 792 / 1 184 Hz（更暗更闷） |
| 收尾 | D5 玻璃余音，0.40 s 时仍有 -21.2 dBFS | 干尾，390 ms 已 -56.2 dBFS |

所以两条的“时间重心”正好相反：升相把能量堆在后半段，落相把能量放在起手。

### 不是纯倒放的实测证据

1. **峰值样点时刻**：落相 4.81 ms，升相 204.56 ms。倒放升相的峰值会出现在 400−204.6 ≈ 195 ms，不可能在前 5 ms。
2. **能量时间重心**（`Σt·y²/Σy²`）：落相 67.2 ms，升相 174.4 ms。
3. **音高方向**：落相 587→392 Hz，升相 392→587 Hz。

### 音色与包络

- **分音**：1 / 2 / 2.756 / 4.07 / 5.404 / 7.4 / 8.933（随基频一起下滑）。
  升相的玻璃 2.756 / 5.404 是长衰减；落相的高泛音衰减只有 11–58 ms，只留 1、2 次分音收尾——
  同一族玻璃/钟体，但泛音“更冷、更短命”。
- **起音**：4 ms 余弦起音 + 1.2–5.5 kHz、12 ms 的槌击边（不是 3–8 kHz 宽带 click）。
- **变暗**：时变一阶低通从 9 kHz 收到 1.5 kHz（τ≈55 ms），跟着下坠一起关高频。
- **落位**：142 ms 一记 792 / 1 184 Hz 的闷触点，给“到底了”一个具体位置。
- **收尾**：最后 140 ms 额外指数收干，390 ms 到 -56.2 dBFS。

|---|---:|---:|

### 响度说明（避免被当成电平 bug）
