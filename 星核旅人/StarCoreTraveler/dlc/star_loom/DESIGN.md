# 星核织机 · 章节设计（DLC 第三章）

分支 `dlc`。全部新内容在 `dlc/star_loom/`；基础三关、`project.godot`、
`export_presets.cfg`、基础 `assets/` 与 `scripts/` 未改。唯一基础菜单改动是
`scripts/start_menu.gd` 的第三个 DLC 入口「星核织机」。

## 标题入口

- `scripts/start_menu.gd` 只增加第三个 DLC 行「星核织机」（y=286），并在创建
  trial / rift / loom 三个 DLC 按钮后统一设置
  `modulate = Color(0.82, 0.86, 0.86, 1.0)`，让「开始游戏」在层级上更突出。
  不改变尺寸、位置、焦点链、热区、开始/设置/退出逻辑。

## 场景

- `star_loom.tscn`：960×360 单厅，地面 y=320；玩家从 x=40 出生，
  向右走到 x=430 触发织机启动。
- 织机本体 (700, 258)：96×96，外框 + 圆环 + 中央插座；两个节点以
  (700, 258) 为中心、椭圆半径 (100, 46) 环绕，角速度 1.15 rad/s。
- 相机跟随玩家，limit 0..960；入场时能先看到空厅与远处的织框，越过入口后
  中右的首领进入画面。
- 背景复用 DS03 云墟（只读），其上叠加本地生成的 960×360 半透明织机厅
  overlay（低 alpha 经线、织框、地面阴影），不使用全屏光斑。

## 相性与命中

- 玩家初始澜相（青），Q 切换辉相（金）/澜相（青）。
- 节点：24×24，1 点生命；只有**异相** J 命中才打掉；同相命中只弹开并显示
  「同相弹开 · Q 切异相再按 J」。节点每 2.6 s 自行换相，所以玩家要读当前
  颜色，而不是只按一次 Q。
- 核心：两个节点都停转后暴露（金色/青色菱形 + 白核）。核心受 3 次真伤
  进入下一阶段；每次真伤后核心换相，玩家必须再按 Q 追相。同相打核心只
  弹开，不计伤害。
- 命中判定：玩家真实 J → `attack_hit_window`（38×40 前向矩形）→ 节点
  36×36 / 核心 80×84。真实 J 按下时自动面向 240 px 内最近的可打目标。

## 阶段与攻击

- 3 个阶段；每阶段 2 个节点 + 核心 3 次真伤。第 3 阶段第 3 次真伤后完成。
- 阶段 1 只使用慢速追踪弹；阶段 2 加入横扫光带；阶段 3 加入召唤浮灵。
  每次攻击前的预警：
  - 追踪弹 0.55 s：3/4/5 个紫环 + 白芯预警点，随后 8×8 追踪弹以 74 px/s、
    0.9 rad/s 转向追击，寿命 9 s，同屏最多 6；
  - 横扫光带 0.65 s：地面高度 22×50 的紫色虚线带 + 横贯全厅的警告车道，
    0.65 s 后从 x=930 以 210 px/s 向左横扫；站着会被打，跳起可躲；
  - 召唤浮灵 0.80 s：2 个紫色裂隙预警，随后生成 1–2 只 16×16 浮灵；
    浮灵 44 px/s 漂移，接触即爆并造成 1 次受击，任意相性 J 一击清除，
    寿命 12 s，同屏最多 3。
- 攻击间隔：预警 → 执行 → 1.0–1.15 s 恢复 → 0.85 s 空闲；阶段切换后
  1.5 s 宽限，失败重置后 1.2 s 宽限。

## 受击、失败与重开

- 玩家的受击保护、击退、红闪全部来自共享 `L3Player`（0.15 s 反应、
  0.6 s 保护）；本章只统计**被接受**的受击。
- 2 次受击 → 0.25 s 淡出 / 0.10 s 黑屏 / 0.35 s 淡入 → 玩家回 x=420
  入口，织机**完整重置**：阶段 1、两个节点、核心受护、0/3、所有弹幕/浮灵
  清除、受击数归零；战斗计时继续。
- R：整章重开，回 x=40、计时归零、织机休眠、完成页隐藏、音乐停止；
  再次越过入口时重新开始。
- 完成页「织机停转 · 用时 mm:ss」；E / Enter 回 `level_01` 标题。
  Esc 暂停页（继续 / 返回标题），Shared guide 仍在开场打开。

## 音乐与音效

- 战斗音乐：`res://dlc/audio/music/loom_boss.ogg`（另一 agent 提供，
  61.7 s，140 BPM）。`loom_audio.gd` 在运行时检查文件存在，加载后把
  `AudioStreamOggVorbis.loop = true` 写在代码里（`.import` 的 loop=false
  不参与）；播放器 -6 dB（源峰值 -8.05 dBFS → 最终约 -14.05 dBFS）；
  织机启动时播放，暂停时随可暂停的 Audio 节点一起停住，完成/回标题停止，
  失败重试继续。
- 缺失文件：不加载、不警告、不报错，战斗静音；`is_music_available()`
  返回 false。
- 10 条本地生成的 WAV：节点命中/崩解、核心受击/暴露、同相拒绝、预警、
  横扫、召唤、阶段、完成；峰值 -3 dBFS，由 `tools/gen_assets.py` 生成。
  玩家挥击/受击/失败/重生仍用共享 `DemoAudio`，不改基础音频。

## 开场说明

- 复用 `dlc/ui/dlc_guide.tscn` 的界面、翻页、长按空格、缺失演示占位；
  不改 `dlc_guide.gd`。`loom_guide.gd` 作为其子类，通过既有
  `_page_data()` / `open_guide()` 提供 3 页 `loom` 页面。
- 3 页：节点相性 / 核心暴露与三段真伤 / 三段攻击与失败重置。
- 3 条演示帧条在 `dlc/ui/demos/`：`loom_nodes`、`loom_core`、
  `loom_attacks`，24 帧 / 8 fps / 256×144，由 `tools/capture_loom_demos.tscn`
  从正式 BOSS 场景实拍（只 debug 摆位/推进阶段，J/Q 都是真实输入）。

## 已知取舍

- 两个节点是纯目标，不做接触伤害；压力来自三段攻击与浮灵。
- 2 次受击是整场共享，不按阶段恢复；这是任务给定的硬规则，配合
  0.55 s 以上预警和较慢弹速保证可完成。
- 阶段 1 只有追踪弹，阶段 2/3 逐步加入扫带和浮灵；如果希望三招从
  第一阶段就全部出现，需要改 `get_attack_pool()`（属于设计变更，未做）。
- 平地上没有坠落点；`kill_y=430` 只作为共享玩家的兜底。
