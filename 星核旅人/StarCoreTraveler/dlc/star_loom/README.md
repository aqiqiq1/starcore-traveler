# 星核织机 · 城内 BOSS 房（DLC3）

> 定位：**未来第四关（入城之后）的 BOSS 房原型**。本轮不接入 `level_03`、完成页或主流程；
> 入口仍是标题菜单第三行「星核织机」，场景文件缺失时该行自动隐藏。

## 怎么进

```powershell
cd "D:/godot game/星核旅人/StarCoreTraveler"
D:/Godot/Godot_v4.7.2-stable_win64_console.exe --path .
# 标题 → 星核织机
```

Esc 暂停（暂停页可继续 / 重开本章 / 返回主界面 / 退出），R 整章重开；
E / Enter 在完成页回标题，完成页也可点「返回主界面」/「重玩本章」；
说明页 F 翻页、长按空格跳过，三个机制提示窗 F 或长按空格关闭。

## 规则速查

- 金/青两只节点绕中央核心旋转；**异相 J** 才能打停节点，同相命中只碎壳。
- 两节点停转后核心暴露；核心每次受创换相，**异相 J 共 3 次**进入下一阶段。
- 3 次受击失败，受击后约 1 秒保护；失败从**当前阶段入口**重开，阶段 1 结束补给一次（受击清零）。
- 攻击池：阶段 1 追踪弹；阶段 2 加横扫光带、地砖火柱；阶段 3 加浮灵、两侧滚齿。
- 城内火盆是装饰常燃；伤害只来自地砖格栅、横扫与齿轮。

## 素材

- 城内背景/前景/地板、208×152 四帧织机、40×40 节点、火盆/格栅/齿轮、弹与浮灵，全部由
  `tools/gen_city_assets.py`（已归档）程序化绘制；音效由 `tools/gen_assets.py` 生成；无外部素材。
- BOSS 音乐 `dlc/audio/music/loom_boss.ogg`，运行时强制循环，播放器 -6 dB。
