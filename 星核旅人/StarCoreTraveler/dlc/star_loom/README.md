# 星核织机 · 城内 BOSS 房（DLC3）

> 定位：**未来第四关（入城之后）的 BOSS 房原型**。本轮不接入 `level_03`、完成页或主流程；
> 入口仍是标题菜单第三行「星核织机」，场景文件缺失时该行自动隐藏。

## 怎么进

```powershell
cd "D:/godot game/星核旅人/StarCoreTraveler"
D:/Godot/Godot_v4.7.2-stable_win64_console.exe --path .
# 标题 → 星核织机
```

Esc 暂停（暂停页可继续 / 重开本章 / 返回主界面 / 退出 / 操作），R 整章重开；
E / Enter 在完成页回标题，完成页也可点「返回主界面」/「重玩本关」；
两页说明页 F 翻页、长按空格跳过；章节内只保留阶段 2 首次火柱提示，
F 或长按空格关闭，R / 阶段重开不会重弹。

## 入厅前的三件本体机制（2026-11-27 补回）

- **同相门**（x=150，复用 `dlc/trial_chambers/polarity_gate.tscn`）：初始澜相被挡，
  Q 换辉相后通过。门上保留 34×34 的日/月标记板、锁扣和 8×88 整色光幕；
  完整「门只认同相」教学已在 L1，DLC3 只在 56 px 接近时提醒「需辉相（日）」，
  撞门不重复。
- **运送星核**（x≈250–330，复用 `scenes/rune_stone_field.tscn` 的力场采样）：入口段
  运送的不再是符文石，而是工程现有的 **星核**（`StarCoreVisual` 的
  `star_core_negative_12f` 青色澜相 12 帧素材，16×16，1:1；它供的是月门）。
  `RuneStoneField` 的 160 px 场、同相斥/异相吸规则、250–330 行程与“无实体碰撞”
  都不变；星核带一圈青色场环、随核色的拖尾和地面投影，**不画外金环**，在
  640×360 下明确是发光核心而不是石头。
  x=330 是 **星核仓**：现有 `star_core_bay_base/glass` 基座/玻璃罩 + 低石座、
  仓体金环和槽唇组成；未入仓时仓体暗、玻璃罩收起，星核进入后基座变白、玻璃罩
  合上、仓环/缝隙/地面导线亮起，打开 x=380 的月门（同一 `PolarityGate` prefab，
  门显月/澜相）。星核可拉回，R 复位；星核/仓都没有实体碰撞，不会顶飞/夹住角色，
  也不能拿来跳过 88 px 门。推送/拉回与入仓供电的完整说明放在 DLC3（说明页 +
  56 px 接近事件行）；DLC2 只提醒「送青核入仓，为月门供电」。
- **检查点**（x=410，复用 `scripts/level_checkpoint.gd`）：走过月门后记录一次；
  失败仍重开当前阶段，但角色从检查点脚底位置恢复。检查点同时把第二道门锁在
  “已开”，防止角色在门右侧把星核拉走后回不了头。R 清空检查点并复位星核/仓/双门。
- 竞技场坐标、核心/节点/火道/齿轮位置未改；Boss 三阶段框架保留，只把首次
  浮灵提前到阶段 1 第一轮（见下）。首局导览与开场电影按 2026-11-27 重做为
  真实织机厅运镜（真实 `OpeningCamera2D` + 真实织机/节点/核心/玩家，灯排与
  核心只是世界光覆盖层）。

## 规则速查

- 金/青两只节点绕中央核心旋转；**异相 J** 才能打停节点，同相命中只碎壳。
- 两节点停转后核心暴露：金网向两侧收开（缝隙 26 px），中央是 **40×40 的
  整块相性菱形**（金 `#f4cd63` / 青 `#5fe1e6`，1 px 深边、白色高光，
  内侧保留紫色核心），上方是太阳/月亮图标。核心每次受创整块换色，**异相
  J 共 3 次**进入下一阶段。首次暴露只有 0.3 s 白色短闪 + 10 颗粒子，不画环。
- 核心命中框 **40×36**，底边离地约 58 px：站地 J 必 MISS，跳起 J 才命中。
- 3 次受击倒下；每次死亡扣 **1 条命**（共 3 颗心），从**门前检查点/当前阶段入口**
  重开；0 条命出 game over 页（重试本章 / 返回标题，R 重置 3 条命）。阶段 1 结束
  补给一次（受击清零），但**不会补命**，也没有无限加命。
- HUD 顶部是一行「章节 / 目标或事件」+ 360×16 Boss 条（阶段/节点/核心/3 条命）；
  左下是固定三格生命条。事件临时替换目标行，0.15 s 交叉淡入淡出；稳定帧只有
  一行，事件结束后目标行回来。暂停/说明页/提示窗/恢复/结算/game over 时隐藏。
- 右上角相性用 16×16 日/月图标：金太阳=辉相、青月=澜相，无文字；核心
  菱形上的日/月图标约 15×15，与 HUD 使用同一套像素几何。
- 攻击池：**阶段 1 第一轮固定一次裂隙浮灵**（原阶段 3 提前，仍是一击可清的单只
  44 px/s 浮灵；之后阶段 1 回到追踪弹池）；阶段 2 加横扫光带、地砖火柱；阶段 3
  加浮灵、两侧滚齿。浮灵数量/血量/伤害未改，只改首次出现时机与阶段分配。
- 城内火盆是装饰常燃；伤害只来自地砖格栅、横扫与齿轮。
- 跑动/走路接共享 `PlayerFootstepAudio`；说明页、提示窗、暂停、失败恢复、
  结算/游戏结束时静音。音乐播放器 `PROCESS_MODE_ALWAYS`，说明页与提示窗
  期间继续；暂停页显式 `stream_paused`。
- 地砖火柱提示只由阶段 2 第一次真实火柱预警触发；进厅/核心暴露不弹窗。

## 素材

- 城内背景/前景/地板由 `tools/gen_city_assets_v2.py`（2026-11-27 美术审计）程序化生成，
  运行时在 `assets/city_v2/`；旧 `assets/city/` 背景/前景/地板保留作回退。208×152 四帧织机、
  40×40 节点、火盆/格栅/齿轮、弹与浮灵仍来自旧 `assets/city/`；音效由 `tools/gen_assets.py`
  生成；无外部素材。
- BOSS 音乐 `dlc/audio/music/loom_boss.ogg`，运行时强制循环，播放器 -6 dB。
- 入口段运送的星核直接使用 `assets/star_core/star_core_positive_12f.png`
  （16×16，12 帧）；星核仓直接使用 `assets/star_core_bay/star_core_bay_base.png`
  与 `star_core_bay_glass.png`（32×32）；龛口/低石座/核心环/导线为代码绘制，
  本轮未新画任何 PNG。
