## 2. 实际看到的连续顺序

1. **0.0–2.25 s**：主角在真实石廊里向右移动。砖墙、红色旗帜、壁灯、青雾和地面植被始终作为实体空间存在；镜头跟人，没有切到黑底，也没有把房间替换成一张背景图。
2. **2.25–2.5 s**：画面短暂压暗，进入同一关卡的 Boss 房间；火把、石柱、拱洞和旗帜继续存在，房间没有被清空。
3. **2.5–5.5 s**：Boss 单独占据画面中心，主角暂时不在镜头里；顶部出现大号 Boss 名。约 3.0–3.5 s 有白色环形脉冲围着 Boss，Boss 同时做出仰身/吼叫动作。房间没有变黑，只是把注意力集中到 Boss。
4. **5.5–7.0 s**：名字淡出；Boss 的地面火焰攻击发生；主角从画面右缘进入**同一个真实房间**，随后镜头里同时有 Boss、主角、火焰和地面。
5. **7.0–10.2 s**：正常战斗。主角和 Boss 共用同一套房间几何与光照；Boss 的体型、颜色和攻击特效是唯一的高亮层。

## 3. 能借鉴 / 不能照搬

能借鉴：

- 先给**真实房间里的机关/Boss**，不是另绘一张黑底插画；房间结构、灯火和地面始终在。
- 用取景把角色暂时移出画面，让机关/Boss 独享一个短 beat；再用真实角色回到同一空间，完成「先机关、后玩家」的注意力移交。
- 一个 beat 只讲一件事：先亮相，再让局部亮起/动作，再回到玩家。本作对应为「两道真实门与暗锁同框 → 金晶体亮、锁环转 → 门缝光落地 → 拉回玩家」。
- 机关的轮廓、动作和局部特效是画面里最亮、最饱和的部分；房间只做低饱和承托。

不能照搬：

- 「The Incomplete One」名号、Concierge 造型/姿态、火焰攻击、石廊的火把/旗帜/拱洞具体布局、配色和像素。
- 原作的房间切镜节奏和 UI 字体；本作 640×360 的天空废墟、`PolarityGate`、金/青晶体和门锁有自己的几何。
- 原视频在 2.25–2.5 s 是**压暗/房间切换**，不是连续横移。本任务要求「向左拉回」，所以我们的连续 Camera2D 拉远是**按任务要求的改编**，不能写成「死亡细胞原样如此」。

## 4. 与本次实现的对应

- 真实场景：`TrialChambers` 的 `Background/CloudRuinsDS03`、`Terrain/Ground`、`Decorations`、`Player`、`GateGold`、`GateCyan`、`PhaseCrystal` 都保留；影片只新增自己的 `OpeningCamera2D` + 世界光层，不再新增任何假晶体节点。
- 门的归属：影片的 `_gate` 就是章节的 `$GateGold`（`PolarityGate` 实例，x=280）。太阳牌、挂锁、8×88 光幕、石柱和碰撞全部由这个真实节点绘制/决定；影片只改它的 `modulate` 并在真实徽章牌外画光，不另画第二道门。
- 晶体与青门：左侧是真实 `PhaseCrystal`（x=214，金）；右侧是真实 `GateCyan`（x=520，青）。两者都是关卡里实际参与规则的节点；原先补在 x=346 的 `SealedCrystal` 已从节点、脚本、截图引用中删除。首关「只有金晶体能翻相、青门必须用 Q」的规则没有改变。
- 镜头：0.0–2.55 s 停在 1.0x 广角（OpeningCamera2D 在 x=400、y=180），可视世界 x=80..720，金门 x=280、青门 x=520、金晶体 x=214 同框；2.55–3.25 s 平移到 x=320、zoom 1.0 的玩家玩法取景；3.25–3.40 s 停住。结束后相机、HUD 与控制交还，门的相性逻辑不变。
- 暗调：开场用屏幕暗调把真实天空废墟压暗，但 0.50 起就保留石柱、门框、太阳牌、金晶体和两道真实门的可读性，不回到黑底。
