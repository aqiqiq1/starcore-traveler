# 极性门呈现参考（2026-11-25）

针对本次唯一新呈现对象：极性门的金／青两态。先联网打开参考，再设计实现。

## 实际打开并核看的来源

- 页面：Celeste Wiki · Core Block
  <https://celeste.ink/wiki/Core_Block>
- 实际看到的两态信息框（页面内 Hot / Cold 切换）：
  - Hot：深炭黑整块，内部是亮红／橙色断续裂纹，向中心汇聚；中心一枚偏白高亮核。
  - Cold：同一轮廓整块转为深蓝，内部是青／浅蓝断续裂纹；中心核为亮青白。
- 页面文字确认两态由 core switch 切换，是同一实体的两种整块配色，而不是换了一套造型。

## 可借鉴 / 不照搬

可借鉴：
- 状态先于细节：整块 8×88 光幕先以金／青整色区分，中央菱形亮核作为第二读点；
- 亮核与暗边的高对比让 1× 像素下仍能一眼读出“当前要求哪一相”；
- 两态共用同一几何轮廓，只换色与内部明暗，玩家不需要重新认形状。

不照搬：
- 不使用 Celeste 的方块像素、裂纹贴图、Hot/Cold 具体造型与弹跳/碎裂玩法；
- 不做“站上去会弹飞／下沉”的交互，本项目的门只做同相可穿、异相阻挡；
- 不复制其背景、字体、音效或调色板；本项目金 #f4cd63、青 #5fe1e6、近黑底沿用现有三关。
