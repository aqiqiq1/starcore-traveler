# 星核试炼场 · 玩法拓展设计（2026-11-25）

分支：`feature/gameplay-expansion-20261125`（备份分支 `backup/demo-20261125`，标签 `demo-backup-20261125`）。只加一个可选试炼关，不改三关主线、剧情、存档或许可。

## 目标

给通关后的 Demo 一个可重复玩的短关卡：用**新机制极性门**做入口筛选，再用现有守卫战斗收尾。玩家从标题菜单进入，完成后回标题；不写新剧情、不新增音频、不扩主线地图。

## 新机制：极性门（PolarityGate）

- 竖直光幕 8×88，1× 像素；金色（辉相）或青色（澜相），中央菱形亮核 + 上下暗边，状态一眼可读。
- 玩家相性与门一致时**碰撞关闭、可穿过**；不一致时实体阻挡。按 Q 切换。
- 防夹：玩家已在门内时保持可穿过，离开后才恢复实体；不做瞬移/伤害。
- 视觉参考：Celeste Core Block 的 hot/cold 两态——整块变色 + 中央亮核，状态先于细节可读；只借这一点，不搬方块造型/像素/玩法。
- 门不读输入、不改玩家相性；只读 `player.is_positive()` 与自身 `required_positive`。

## 关卡

单场景 `scenes/trial/trial_chambers.tscn`，1280×360，横向镜头跟随；背景复用 DS03，地面/柱/守卫复用现有资产。

1. **入口（x≈0–420）**：出生点；第一道金门 x≈280，玩家初始为澜相，必须 Q 成辉相穿过；第二道青门 x≈520，再 Q 回澜相。
2. **过渡（x≈420–820）**：一小段石台/矮柱，不新增跳跃参数；可放一处符石力场做节奏，但不强制。
3. **守卫试炼（x≈820–1240）**：进入竞技场后守卫激活；击败守卫（3 点真伤）才开完成点。玩家可用现有 J/受击/复活规则；失败回竞技场入口，R 重开试炼。
4. **完成（x≈1220）**：触碰完成点弹出“试炼完成 · 用时 mm:ss”，E/Enter 返回标题；不写主线结算。

HUD：左上“星核试炼场”，一行短目标；右上显示当前相性（辉/澜）。暂停只做“继续 / 返回标题”两项，不复制完整设置页。
