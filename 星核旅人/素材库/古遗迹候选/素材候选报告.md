# 古遗迹地图与星核素材审核结果

## 结论

推荐先用 **Szadi Pixel Platformer World 地图＋16px 星核**做原型；STONE RUINS 作为完整替代方案保留，不与主推荐前景混拼。两套地图与星核均已下载，有原包及许可依据，已完成一次美术方向 Agent 审查和协调者复核。暂不扩大检索；现阶段缺口是少量机关状态、云海表达与引擎适配，不需要再搜索一整套世界素材。

以上是条件推荐，不代表创作者已经选定最终地图，也不代表完成 Godot 导入或玩法验证。

## 1. 地图主推荐：Szadi Pixel Platformer World

- 作者：Szadi art.；原链：https://szadiart.itch.io/pixel-platformer-world
- 原包：`01_szadi_pixel_platformer_world/source/PixelPlatformerSet2v.1.1.zip`
- 用图：`01_szadi_pixel_platformer_world/extracted_map/`，包含 A/B 地形、六层背景与火把/钻石帧。
- 匹配理由：细碎石材、暗轮廓和建筑裂纹能接住角色的细像素盔甲；具备岩台断面、砖平台和拱柱，有三关复用空间。
- 使用要求：三关先统一一种石色；较亮地形承接玩家，暗结构放背景。当前红天与黑林只是演示选择，不等于已满足云海悬城。
- 不足：背景不是现成云海浮城；尚未验证完整拼接规则、落脚边界和可碰撞模块；门、石座和符文石状态需用现成外壳轻量补足。
- 许可：包内作者声明允许个人/商业使用与修改，署名非必需，禁止出售素材包。属于自定义文本，不标成标准 CC0。公开分发包含原始素材的源工程，须先确认许可边界。

## 2. 地图备选：STONE RUINS

- 作者：NicoPardo；原链：https://nicopardo.itch.io/stone-ruins
- 原包：`02_stone_ruins/source/Stone Ruins.rar`
- 用图：`02_stone_ruins/extracted/Stone Ruins/`，包含 TileSet、TilesGround、Objects、BackGround 四张 PNG。
- 匹配理由：蓝灰石砖衬托紫红围巾，平台直边容易读图，古遗迹特征明确。
- 条件：纹理比角色更简化，作为完整替代尚可；不要混进 Szadi 前景。悬空底部与自然崩裂边缘较弱，需先试拼一个断桥小段，不投入大量补画。
- 不足：七组地形预制件不等于完整自动地形规则，无云海浮城背景；部分背景横梁需压暗，不能误读为落脚平台。
- 许可：包内明确允许个人/商业项目和修改，署名非必需；原始素材随公开源工程再分发的范围未明确，先用于内部原型，不据此断言可公开分享源资产。

## 3. 星核：Free Shiny Gem “Round”

- 作者：Frakassets；原链：https://frakassets.itch.io/free-shiny-gem-round
- 原包：`03_star_core_gem/source/free_gem_round_frakassets.zip`
- 推荐起点：`03_star_core_gem/extracted/free_gem_round_frakassets/gem_round_16x16_12f_0d.png`，先取正面静帧试装，再考虑旋转。
- 16px 表为 192×16、12 帧；32px 表为 384×32、12 帧，提供不同视角和表现变体。
- 适配：16px 约不到半身高，比例可用；原粉紫高亮会和围巾争色，建议轻量降低饱和度或换为少量冷色阶，必要时细暗边。正负标识独立于颜色与旋转。
- 风险：旋转侧面帧会变薄，碰撞体不能跟随视觉缩窄；32px 不作默认体量，但保留原包完整性，不因它未被选用而称整包不合格。
- `_normal.png` 是法线贴图，不是普通彩色版；基础版本不要求法线光照。
- 许可：资源页标 CC BY 4.0，可修改与分发，须署名、链接许可并注明修改。原包无单独 LICENSE，以保存页面及 CC BY 法律文本为证据。
- 建议署名：`Free Shiny Gem "Round" by Frakassets — https://frakassets.itch.io/free-shiny-gem-round — CC BY 4.0 — 修改情况按实际填写。`

## 4. 已核实与未核实

- 素材检索阶段已保存作者页面和许可说明，检查下载图像与网格，并制作本地拼图。
- 美术 Agent 已查看角色、两套地图原图和代表性星核变体，形成 `美术审查.md`。
- 协调者已读取三份 PAGE_EVIDENCE、两地图包内许可，查看人物搭配预览、Szadi 建筑构件和16px彩色星核，并计算三个保留原包 SHA256。
- 未在 Godot 中测试导入、切片、碰撞、动画、同逻辑分辨率比例或关卡可解性。预览均非引擎实景，且地图预览处理尺度不同，不能直接据此比较原始像素密度。
- 用户提供角色的来源许可仍待补充，不因环境许可通过而自动认为角色可发布。

## 5. 清理结果

- 已移除本轮重新下载的 Classical Ruin Tiles 对照图与原图：非本轮优先方向，已有两套更值得试装的候选，不重复囤积。
- 已移除 `_review` 临时提取副本和包内附带的非目标角色提取文件；三个分类目录保留所需原包、地图/星核与许可。
- `_downloads` 中三个重复原包已校验与分类目录原包哈希一致，但被其他进程占用，删除失败。暂不强行终止未知进程；分类目录是正式保留位置，残留副本待释放后清理，不作第二份推荐。
- 两套地图均达到候选保留标准，星核有条件保留，因此不为“必须删除一个”而丢弃合格备选。
